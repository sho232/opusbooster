# MetaピクセルとコンバージョンAPI

{% hint style="info" %}
**Metaピクセル**は、ページの表示やフォームの送信などの出来事（イベント）を Meta に知らせる仕組みです。Meta 広告（Facebook・Instagram）の成果を数えたり、広告の配信を賢くしたりするのに使います。

**コンバージョンAPI** を有効にすると、同じイベントを訪問者のブラウザからだけでなく、OpusBooster のサーバーからも Meta に送ります。広告ブロッカーやブラウザの追跡防止で止められた分も、取りこぼしにくくなります。
{% endhint %}

設定は、次の4段階です。

1. Meta 側で Metaピクセル（データセット）を作る
2. ピクセルID を控える
3. Meta 側でアクセストークンを出す
4. OpusBooster 側でピクセルID とアクセストークンを入れる

## 送られるイベント

OpusBooster のサイトやファネルでは、次のイベントが自動で送られます。コンバージョンAPI を有効にすると、これらはブラウザとサーバーの両方から送られ、Meta 側で1件にまとめられます。

* **ページビュー** - ページが表示されるたびに送られます。
* **リード** - フォームが送信されたとき、または予約が入ったときに送られます。メールアドレスの入力欄が無い、ボタン代わりのフォームでも送られます。
* **カートに追加** - 商品がカートに入ったときに送られます（商品名・価格・通貨・数量）。
* **チェックアウトを開始** - 決済ページが開かれたときに送られます（注文合計・通貨・注文内容）。
* **購入** - 決済（またはアップセル・ダウンセル）が完了したときに送られます。
* **コンテンツビュー** - ネットショップの商品ページが見られたときに送られます。
* **登録完了** - サイトやファネルで会員登録が済んだときに送られます。

{% hint style="warning" %}
**カスタムコードで足したイベントは、サーバーからは送られません。**

カスタムコードの欄に `fbq('track', …)` を書いて足したイベントは、訪問者のブラウザからしか送られません。コンバージョンAPI を有効にしていても同じです。広告の成果として数えるイベントは、できるだけ上の一覧にあるもの（フォームの送信ならリード）を使ってください。
{% endhint %}

{% hint style="warning" %}
カスタムコードの欄に Metaピクセルのコード（ベースコード）を貼っている場合は、そのコードを消してから、この記事の設定をしてください。両方あると、同じイベントが二重に送られます。
{% endhint %}

## 1. Metaピクセル（データセット）を作る

すでに Metaピクセルを持っている場合は、この手順は飛ばして「2. ピクセルID を控える」に進んでください。

{% hint style="info" %}
Meta の画面では、Metaピクセルは「**データセット**」と呼ばれています。同じものです。
{% endhint %}

1. Meta の [イベントマネージャ](https://business.facebook.com/events_manager2/) を開きます。
2. 左のメニューの **データをリンク** を押します。
3. **ウェブ** を選んで **次へ** を押します。
4. **新しいデータセットを作成** を押します。
5. **名前を入力** に、分かりやすい名前（例：サイト名）を入れます。
6. **作成** を押します。

## 2. ピクセルID を控える

ピクセルID は、Metaピクセル（データセット）ごとに付いている数字です。

1. イベントマネージャの左のメニューで **データセット** を開きます。
2. 一覧から、使うデータセットを選びます。名前の下に出ている **ID** の数字が、ピクセルID です。
3. 選んだデータセットの **設定** タブを開くと、一番上の **データセットID** にも同じ数字が出ています。

## 3. アクセストークンを出す

アクセストークンは、OpusBooster のサーバーが、あなたのデータセットにイベントを送るための鍵です。

1. イベントマネージャで、使うデータセットを選び、**設定** タブを開きます。
2. 下へ進み、**コンバージョンAPI** の欄を探します。
3. **ダイレクト連携を設定** の中の **アクセストークンを生成** を押します。
4. 出てきたトークンをコピーします。

{% hint style="danger" %}
アクセストークンは、他の人に見せたり、メールやチャットに貼ったりしないでください。
{% endhint %}

## 4. OpusBooster 側で設定する

1. ビルダーを開き、左の **歯車**（ホームページの設定）を押します。
2. **アプリケーション** を開き、**アプリケーションを追加** を押します。
3. 一覧の **Facebook Pixel** の **接続** を押します。
4. **Facebook Pixel ID** に、手順2 で控えた数字を入れます。
5. **コンバージョンAPIの有効化** にチェックを入れます。
6. 出てきた **コンバージョンズAPIアクセストークン** に、手順3 でコピーしたトークンを貼ります。
7. **保存して確認** を押します。

{% hint style="info" %}
Metaピクセルを追加すると、商品フィードの URL も表示されます。この URL は、ネットショップの商品から Facebook と Instagram のショップを作るときに使います。
{% endhint %}

## 動いているかを確かめる

イベントが Meta の画面に出るまで、20〜30分ほどかかります。

1. 設定したサイトのページを開いたり、フォームを送信したりします。
2. 30分ほどたってから、イベントマネージャで使うデータセットを開き、**概要** タブを見ます。
3. 下の一覧で、イベントごとの **連携** の欄を見ます。

| 連携の表示 | 意味 |
| --- | --- |
| 複数 | ブラウザとサーバーの両方から届いています（コンバージョンAPI が動いています） |
| Metaピクセル | ブラウザからだけ届いています |
| コンバージョンAPI | サーバーからだけ届いています |

ページビューやリードが **複数** になっていれば、設定は完了です。

## スマートリンクのテンプレートで、配信サービスごとに数える

音楽アーティスト向けのスマートリンクのテンプレート（各配信サービスへのボタンが並んだページ）では、どのボタンが押されても **リード** が送られます。広告の成果として「ボタンが押されたか」を数える、広告をそれで最適化する、という使い方なら、ここまでの設定だけで足ります。

「Spotify が何回、Apple Music が何回」とサービスごとに分けて見たいときは、サービスごとに **カスタムコンバージョン** を1つずつ作ります。

{% hint style="info" %}
テンプレートには、押されたサービスを見分けるためのコードが入っています。ボタンを押した人は、いったん同じページに `?ob_go=spotify` のような印が付いた URL で戻ってから、配信サービスへ移ります。カスタムコンバージョンは、この印を目印にして数えます。
{% endhint %}

1. イベントマネージャの左のメニューで **カスタムコンバージョン** を開き、**カスタムコンバージョンを作成** を押します。
2. **名前** に、分かりやすい名前（例：Spotify へのクリック）を入れます。
3. **データソース** で、手順2 で控えたピクセル（データセット）を選びます。
4. **アクションソース** は **ウェブサイト**、**イベント** は **すべてのURLトラフィック** のままにします。
5. **ルール** を **URL** ・ **が次を含む** にして、下の表の文字を入れます（例：`ob_go=spotify`）。
6. **作成** を押します。
7. 数えたいサービスの数だけ、1〜6 をくり返します。

| サービス | ルールに入れる文字 |
| --- | --- |
| Spotify | `ob_go=spotify` |
| Apple Music | `ob_go=applemusic` |
| YouTube | `ob_go=youtube` |
| YouTube Music | `ob_go=youtubemusic` |
| Amazon Music | `ob_go=amazonmusic` |
| SoundCloud | `ob_go=soundcloud` |
| iTunes | `ob_go=itunes` |

{% hint style="warning" %}
カスタムコンバージョンは、作ったあとに押された分から数え始めます。作る前の分はさかのぼって数えられません。最初の1件が届くまでは「非アクティブ」と表示され、届いてから20〜30分ほどで「アクティブ」に変わります。
{% endhint %}
