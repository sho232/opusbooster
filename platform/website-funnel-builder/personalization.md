# 見ている人に合わせて、ページの文章を変える（パーソナライズ）

メールでは「〇〇さん」と名前が入るのに、ページを開くと誰にでも同じ文章。そんなときに使うのが**パーソナライズ**です。

ページの文章に決まった**印**（パーソナライズ・タグ）を書いておくと、表示するときに、見ている人に合わせた中身に置き換わります。人は、自分宛てに書かれた文章ほどよく読みます。

## 設定はどこにあるか

1. ビルダーを開きます
2. 画面左のアイコンの列にある**歯車のアイコン**（サイト全体・ファネル全体の設定）を押します
3. 一覧から「**パーソナライズ**」を選びます

{% hint style="info" %}
ページの横にある歯車（「ページの編集」が開くもの）とは別です。左のアイコンの列の、下から2番目の歯車です。
{% endhint %}

## 使える印

「**システムプロパティ**」に、最初から使える印が並んでいます。

| 名前 | 印 | 置き換わるもの |
| --- | --- | --- |
| メンバーの名 | `{member.first_name}` | ログインしたメンバーの名前 |
| メンバーの姓 | `{member.last_name}` | ログインしたメンバーの姓 |
| メンバーのメール | `{member.email}` | ログインしたメンバーのメールアドレス |
| URLパラメータ | `{param.name}` | ページのアドレスに付けた値 |
| 現在の年 | `{current_year}` | 今年の年（例: 2026） |

それぞれの右にあるボタンで印をコピーできます。コピーした印を、ページの文章に貼るだけです。

* **会員ページ**の見出しに「メンバーの名」の印を入れると、ログインした人の名前が出ます
* **フッター**の著作権表示の年を「現在の年」の印にしておくと、毎年直す必要がなくなります

## URLに付けた名前を、見出しに出す

メールやLINEで送るリンクに名前を付けておくと、開いた人のページに、その名前を出せます。

1. 見出しの文章に、URLパラメータの印を入れます（例: `{param.name}さん、ようこそ`）
2. ページを保存します
3. ページのアドレスの最後に `?name=佐藤` のように付けて開きます
4. 見出しが「佐藤さん、ようこそ」になっていたら完成です

{% hint style="warning" %}
**印の中の名前と、アドレスに付ける名前は、同じ文字にしてください**

印が `{param.name}` なら、アドレスには `?name=…` を付けます。`{param.course}` にしたなら `?course=…` です。違う文字だと置き換わりません。

画面の説明では、名前の大文字・小文字は区別されず、スペースは `_` に置き換えて扱われます（`?First%20Name=John` は `{param.first_name}` で受け取れます）。
{% endhint %}

## メールのリンクに、受け取った人の名前を入れる

メールを送るときに、相手ごとの名前をURLに入れておけば、開いた人のページにその人の名前を出せます。メールの本文では、受け取る人の項目を次の書き方で差し込めます（本文をクリックして出るツールバーの「**タグの追加**」から選べます）。

| ツールバーの名前 | 書き方 |
| --- | --- |
| 名 | `{first_name}` |
| 名字 | `{last_name}` |
| 名前 | `{name}` |

メールの本文に、次のように**URLを文字のまま**書きます。

```
https://あなたのドメイン/ページ名?name={first_name}
```

送ると `{first_name}` が一人ひとりの名前に置き換わり、受け取った人がURLを押すと、ページの見出しにその名前が出ます。

{% hint style="warning" %}
**リンクのボタンにせず、URLを文字のまま書いてください**

メールの文字に「リンク」を付けたり、ボタンにしたりすると、クリック数を数える仕組みを通るときに日本語の名前が「??」に変わってしまいます。URLを本文にそのまま書けば、多くのメールアプリでは自動的に押せる形になり、名前も崩れません（ただし、このURLのクリック数は記録されません）。
{% endhint %}

{% hint style="info" %}
**`{name}` ではなく `{first_name}` を使ってください**

`{name}` は「天野 翔」のように空白が入るので、メールアプリが空白の手前でリンクを切ってしまいます。日本語の名前は、空白の前の部分が「名」（`{first_name}`）に入るため、`{first_name}さん` と書くと「天野さん」のように名字で呼ぶ形になります。
{% endhint %}

## 自分で印を作る

「**パーソナライゼーションタグを追加する**」から、自分用の印（動的プロパティ）を作って、ページで使うこともできます。
