# ホームページに使うページを変更する

サイトのアドレスを開いたときに最初に表示されるページを「ホームページ」と呼びます。どのページをホームページにするかは、あとから変更できます。

たとえば「ブログ集客スターター」では、**ブログがホームページに設定されています**。記事の一覧がそのままサイトの顔になる作りです。これを「ホーム」などの別のページに変えることもできます。

## 先に知っておいてほしいこと

ホームページがブログに設定されていると、左メニューの［ウェブサイト］を開いたときに**ブログの管理画面**が表示されます。この画面にページの一覧はありません。

ページの一覧は編集画面（ビルダー）の中にあります。そのため、まず編集画面を開くところから始めます。

## 手順

1. 左メニューの［**ブログヘッダー**］をクリックします（編集画面が開けば、どこからでもかまいません）
2. 画面左のツールバーの一番上、**三本線のアイコン**をクリックします
3. 「ページ ＆ ポップアップ」が開きます。［**PAGES**］をクリックすると、その中のページが表示されます
4. ホームページにしたいページの**歯車アイコン**をクリックして、［**設定を表示する**］を選びます
5. 開いた画面の左下にある［**ホームのページとして設定**］をクリックします

家のアイコンが付いているページが、現在のホームページです。

{% hint style="info" %}
**ページの追加も同じ場所からできます**\
「ページ ＆ ポップアップ」の上部にある［新しく追加する］から、新しいページを作れます。詳しくは[新規ページの追加](add-pages.md)をご覧ください。
{% endhint %}

## 変更したあと

ブログをホームページから外すと、サイトのトップは選んだページに変わります。ブログの記事一覧は、引き続き「（あなたのドメイン）/blog」で見られます。

記事のURLは変わりません。すでに公開した記事や、SNSでシェアしたリンクはそのまま使えます。

{% hint style="warning" %}
**サイトのメニューも確認してください**\
ホームページを変えると、訪問者の入口が変わります。サイト上部のメニューにブログへのリンクが入っているか、確認しておくと安心です。
{% endhint %}
