# 特商法の設定マニュアル（個人事業主）

## どこに書くの？

「**ネットショップ**」→「**設定**」→「**チェックアウト**」タブを開くと、「**特商法に基づく表記**」という入力欄があります。

ここは**1つの欄に、必要な項目をまとめて書く**形です。項目ごとに欄が分かれているわけではないので、下の書き方の例をコピーして、ご自身の内容に書き換えて使ってください。

ここに書いた内容は、購入手続きのページの下に表示されます。

入力を始めると、画面の下に「**変更内容を保存**」ボタンが出てきます。書き終わったら、このボタンを押して保存してください。

## 書き方の例

レッスンやオンライン講座を販売する場合の例です。`［ ］` の部分を書き換えてください。

```
事業者の氏名
［山田 花子］

事業者の所在地
請求があれば遅滞なく開示します

事業者の電話番号
請求があれば遅滞なく開示します

お問い合わせ
［info@example.com］

販売価格
各商品ページに表示された金額（税込）です。

商品代金以外に必要な料金
［なし］
（オンラインの場合は「インターネット接続にかかる通信料はお客様のご負担です」など）

お支払い方法
［クレジットカード］

お支払いの時期
お申し込み時にお支払いが確定します。

サービスの提供時期
［お支払い確認後、予約されたレッスン日時に提供します］

キャンセル・返金について
［レッスン日の3日前までのキャンセルは全額返金します。それ以降のキャンセルは返金できません］
```

## 各項目の書き方のポイント

* **事業者の氏名** — 本人確認書類と同じ**正式な氏名**を書きます。ひらがな・カタカナだけの表記や、教室名・ショップ名だけでは足りません。教室名も載せたいときは「山田 花子（やまだピアノ教室）」のように並べて書きます。
* **所在地と電話番号** — そのまま載せてもかまいませんが、自宅の住所や携帯番号を載せたくない場合は「**請求があれば遅滞なく開示します**」と書けば省けます。詳しくは → [事業者の住所や電話番号を、ページに載せずに済ませられますか](hide-business-address.md)
* **住所を載せる場合** — 「丁目・番・号」や部屋番号まで省かずに書きます。
* **お問い合わせ** — 住所や電話番号を省く場合は、メールアドレスかお問い合わせフォームを必ず載せておきます。
* **キャンセル・返金** — 返金しない場合も、そのことをはっきり書きます。品物を販売する場合は特に大事で、返品のルールが書かれていないと、届いてから8日以内の返品を受け付けなければならない場合があります。
* **月謝やサブスクリプション** — 定期的に支払うものを販売する場合は、支払いの間隔（毎月など）と、解約の方法・締め切りも書き加えてください。
* **商品を発送する場合** — 発送の時期（「ご注文から5日以内に発送します」など）と送料も書き加えてください。

{% hint style="info" %}
メッセージ & ワークフローでメルマガや自動メールを送る場合は、この表記とは別に、メールに住所を載せる必要があります。→ [メール配信に必要な住所の設定（自宅住所を出したくない方へ）](../email-and-automation/business-address-for-email.md)
{% endhint %}

{% endhint %}
