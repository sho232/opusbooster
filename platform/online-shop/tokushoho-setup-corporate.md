# 特商法の設定マニュアル（法人）

## どこに書くの？

「**ネットショップ**」→「**設定**」→「**チェックアウト**」タブを開くと、「**特商法に基づく表記**」という入力欄があります。

ここは**1つの欄に、必要な項目をまとめて書く**形です。項目ごとに欄が分かれているわけではないので、下の書き方の例をコピーして、御社の内容に書き換えて使ってください。

ここに書いた内容は、購入手続きのページの下に表示されます。

入力を始めると、画面の下に「**変更内容を保存**」ボタンが出てきます。書き終わったら、このボタンを押して保存してください。

## 書き方の例

講座や商品を販売する場合の例です。`［ ］` の部分を書き換えてください。

```
販売事業者
［オーパスブースター株式会社］

運営責任者
［代表取締役 山田 太郎］

所在地
［〒170-0005 東京都豊島区南池袋5-13-2 フリード南池袋701］

電話番号
［03-0000-0000］
（受付時間：［平日 10:00〜18:00］）

お問い合わせ
［info@example.com］

販売価格
各商品ページに表示された金額（税込）です。

商品代金以外に必要な料金
［送料：全国一律 800円（税込）］
（オンラインの場合は「インターネット接続にかかる通信料はお客様のご負担です」など）

お支払い方法
［クレジットカード、銀行振込］

お支払いの時期
［クレジットカード：ご注文時にお支払いが確定します。銀行振込：ご注文から7日以内にお振り込みください。］

商品の引き渡し・サービスの提供時期
［ご入金確認後、5営業日以内に発送します］

返品・キャンセルについて
［商品に不良があった場合は、到着から7日以内にご連絡ください。お客様のご都合による返品はお受けしていません］
```

## 各項目の書き方のポイント

* **販売事業者** — 登記簿に記載されている正式な法人名を書きます。ショップ名やサービス名も見せたいときは「オーパスブースター株式会社（OpusBoosterストア）」のように並べて書きます。
* **運営責任者** — 代表者か、通信販売の業務の責任者の氏名を書きます。本人確認書類と同じ**正式な氏名**で、ひらがな・カタカナだけの表記は避けてください。
* **所在地** — 本店か、実際に業務をしている事業所の住所を書きます。「丁目・番・号」や階数・部屋番号まで省かずに書きます。
* **電話番号** — お客さまがつながる番号を書きます。受付時間も添えておくと親切です。
* **返品・キャンセル** — 返品を受けない場合も、そのことをはっきり書きます。返品のルールが書かれていないと、商品が届いてから8日以内の返品を受け付けなければならない場合があります。
* **定期購入やサブスクリプション** — 支払いの間隔（毎月など）と、解約の方法・締め切りも書き加えてください。

## 特商法やプライバシーポリシーの独立したページも作っておきましょう

ここに書いた特商法の表記・個人情報保護方針・利用規約は、**購入フォームやチェックアウトウィジェットの下に出るボタンから読む形**で表示されます。サイトの中に、それぞれの独立したページができるわけではありません。

そのため、次のような場面ではURLのある独立したページが必要になります。

* サイトのフッター（ページの一番下）に「特定商取引法に基づく表記」「プライバシーポリシー」のリンクを置きたい
* Stripeなどの決済サービスの登録画面で、特商法のページのURLを入力するよう求められた

サイトに新しいページを作り、ここに書いたのと同じ内容を貼り付けてください。ページの作り方は → [新規ページの追加](../website-funnel-builder/add-pages.md)

{% hint style="warning" %}
**内容を変えるときは、2か所とも直してください。** ネットショップの設定と独立したページは、自動ではつながっていません。片方だけ直すと、場所によって違う内容が表示されてしまいます。
{% endhint %}

{% hint style="info" %}
メッセージ & ワークフローでメルマガや自動メールを送る場合は、この表記とは別に、メールに送り主の名前と住所を載せる必要があります。→ [メール配信に必要な住所の設定](../email-and-automation/business-address-for-email.md)
{% endhint %}

{% hint style="warning" %}
この記事は一般的な書き方のご案内です。御社の事業に当てはまるかの最終的な判断は、弁護士などの専門家にご確認ください。
{% endhint %}
