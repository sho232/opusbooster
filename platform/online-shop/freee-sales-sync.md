# 売上を会計ソフト freee に取り込む（PayPal・Stripe）

OpusBooster のネットショップやファネルで受け取った売上は、会計ソフトの freee に自動で取り込めます。PayPal で受け取った分も、Stripe（カード）で受け取った分も取り込めます。設定するのは freee の側だけです。OpusBooster の側で設定することはありません。

{% hint style="info" %}
この記事の freee の手順は、freee の公式ヘルプ（2026年11月時点）をもとにしています。画面や手順は変わることがあります。最新の内容は、freee の次のページをご覧ください。

* [PayPal（ペイパル） - 購入履歴・売上データを取り込む](https://support.freee.co.jp/hc/ja/articles/207836913)
* [Stripe - 売上データを取り込む](https://support.freee.co.jp/hc/ja/articles/360001102243)
{% endhint %}

## しくみ

freee では、PayPal や Stripe を、銀行口座と同じ「口座」のひとつとして登録します。登録すると、売上、手数料、銀行への出金が、明細として freee に入ってきます。入ってきた明細を、freee の「自動で経理」で確かめて登録すると、帳簿に入ります。

PayPal と Stripe の両方を使っている場合は、それぞれを別の口座として登録します。

## できること、できないこと

| 内容 | PayPal | Stripe |
| --- | --- | --- |
| 売上の明細を、freee に自動で取り込む | できます | できます |
| 決済の手数料、銀行への出金の明細を取り込む | できます | できます |
| 毎月など定期の支払いの明細を取り込む | できます | できます |
| 外貨（日本円以外）で受け取った売上を取り込む | できません | freee のヘルプに記載がありません |

請求書や領収書については、この記事の「請求書や領収書を求められたら」をご覧ください。

## 先に用意するもの

1. freee 会計のアカウント
2. OpusBooster につないでいる PayPal、または Stripe のアカウントのログイン情報

{% hint style="warning" %}
**PayPal の方へ**

PayPal に登録したメールアドレスが未認証のままだと、つなぐ途中で freee にエラーが出ます。PayPal から届いている「新規アカウントの利用開始」のメールでアドレスを認証してから、もう一度つないでください。
{% endhint %}

## freee につなぐ

途中までは、PayPal も Stripe も同じ手順です。

1. freee 会計を開き、「マスタ・口座」のメニューから「口座」を押します。
2. 「＋登録」を押します。口座のカテゴリは「その他連携先」、データの取得方法は「自動で取得」を選び、「登録」を押します。
3. 「連携先を選択してください」の画面で、PayPal または Stripe を検索して選び、「次へ」を押します。
4. PayPal または Stripe の画面に移ります。下の説明に沿って、ログインします。
5. freee の「口座」の一覧に戻り、データの更新が始まります。終わると、取り込んだ明細の数が、その口座の欄に出ます。

### PayPal の画面で

OpusBooster につないでいるのと同じ PayPal のアカウントでログインし、許可します。

### Stripe の画面で

1. Stripe で使っているメールアドレスを入れて、「続ける」を押します。
2. パスワードを入れて、「ログイン」を押します。
3. 2段階認証を設定している場合は、認証コードを入れます。

{% hint style="warning" %}
**Stripe の方へ**

Stripe に登録していないメールアドレスを入れると、新しい Stripe のアカウントを作る画面に進んでしまいます。OpusBooster につないでいる Stripe のアカウントのメールアドレスを入れてください。
{% endhint %}

## 取り込まれる範囲

* PayPal: 同期した日からさかのぼって、3年以内の明細が取り込まれます。
* Stripe: 「利用可能日」が同期した日以前の取引が取り込まれます。利用可能日は、Stripe の管理画面の「すべての取引」で確かめられます。お客様が支払った直後の売上は、利用可能日が来るまで freee に出ません。

## 取り込んだ明細を登録する

明細は、取り込んだだけでは帳簿に入りません。freee の「自動で経理」で、内容を確かめて登録します。

1. freee のホーム画面の口座の一覧で、「PayPal」または「Stripe」の欄に出ているオレンジ色の数字を押します。
2. 「自動で経理」の画面で、明細ごとに勘定科目を選んで登録します。

よく出る明細と、freee のヘルプに載っている扱いの例です。

### PayPal の明細

| freee での表記 | 中身 | 扱いの例 |
| --- | --- | --- |
| PayPal決済（入金） | お客様からの1回ごとの支払い | 売上高など |
| PayPal定期決済（入金） | 定期の支払い | 売上高など |
| お名前のあとに（PayPal手数料）と付いた明細 | PayPal の決済手数料 | 支払手数料など |
| 銀行への引き出し（出金） | PayPal の残高を銀行口座に移したもの | PayPal の口座から銀行口座への「口座振替」 |

### Stripe の明細

| freee での表記 | 中身 | 扱いの例 |
| --- | --- | --- |
| 支払い（入金） | お客様がカードなどで支払った売上 | 売上高 |
| Stripeの手数料 | Stripe の決済手数料 | 支払手数料 |
| 返金（出金） | お客様への返金 | 売上戻り高 |
| 入金（出金） | Stripe の残高を銀行口座に移したもの | Stripe の口座から銀行口座への「口座振替」 |

{% hint style="info" %}
**Stripe の「入金」は、売上ではありません**

Stripe の明細で「入金」と出るのは、Stripe から銀行口座へお金を移した記録です。freee では出金の明細として出ます。お客様からの売上は「支払い」のほうです。
{% endhint %}

{% hint style="warning" %}
**銀行口座も freee につないでいる場合**

PayPal や Stripe から銀行口座へ移したお金は、PayPal・Stripe の側と、銀行の側の両方に明細が出ます。片方を「口座振替」として登録し、もう片方は「無視」にしてください。両方を登録すると、同じお金を2回数えることになります。
{% endhint %}

同じ種類の明細が続くときは、freee の「自動登録ルール」を作っておくと、次からは勘定科目が自動で入ります。

## どの商品の売上かを確かめる

freee に入るのは、決済ごとの入出金の明細です。明細だけでは、どの商品の売上か分からないことがあります。商品ごとに分けて記録したいときは、OpusBooster の注文の一覧（[注文の管理](https://docs.opusbooster.com/platform/online-shop/order-management)）を開き、同じ日付と金額の注文を探して、freee の明細の備考に商品の名前を書き足します。

## 請求書や領収書を求められたら

OpusBooster の注文の画面では、注文ごとに、内容をお客様へメールで送ることと、印刷することができます。注文の番号の横にあるアクションから選びます。くわしくは [注文の管理](https://docs.opusbooster.com/platform/online-shop/order-management) をご覧ください。

これは注文の内容の控えです。宛名やただし書きを入れた領収書や、登録番号の入った請求書が必要なときは、freee など、お使いの会計ソフトや請求書のサービスで作って送ってください。

適格請求書（インボイス）として出す必要があるかどうかは、事業の形によって違います。判断に迷うときは、税理士や税務署にご確認ください。

## よくある質問

**PayPal で、外貨で受け取った売上はどうすればいいですか**
freee の同期では取り込まれません。日本円に換算して、freee に手で登録します。くわしくは、freee の「外貨取引を登録する」をご覧ください。

**PayPal が自動でつながらないときは**
PayPal の取引の履歴を CSV で書き出して、freee の PayPal の口座にアップロードする方法があります。手順は、上の freee のヘルプの「参考：ペイパルの利用履歴を手動で freee に取り込む」をご覧ください。

**Stripe で受け取ったばかりの売上が、freee に出ません**
Stripe の売上は、利用可能日が来てから取り込まれます。Stripe の管理画面の「すべての取引」で、その売上の利用可能日を確かめてください。

**うまくつながらないときは**
freee のヘルプ「口座が連携（同期）できない時の対処方法」をご覧ください。

**freee 以外の会計ソフトでも、同じことができますか**
PayPal や Stripe の明細を取り込めるかどうかは、会計ソフトによって違います。お使いの会計ソフトのヘルプで「PayPal」「Stripe」を検索してみてください。

**OpusBooster の側で、何か設定は要りますか**
要りません。freee は PayPal や Stripe から直接、明細を受け取ります。
