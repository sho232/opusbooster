# 事業者の住所や電話番号を、ページに載せずに済ませられますか

## 結論: 特商法の表記は「請求があれば開示」で大丈夫です

特定商取引法に基づく表記では、**「請求があれば遅滞なく開示します」と書いておけば、住所と電話番号をページに載せなくてもかまいません。** 通信販売の広告に認められている書き方で、自宅でレッスンをしている先生や個人のショップでよく使われています。

書き方の例:

| 項目 | 書き方の例 |
| --- | --- |
| 事業者の氏名 | 山田 花子 |
| 事業者の所在地 | 請求があれば遅滞なく開示します |
| 事業者の連絡先 | 請求があれば遅滞なく開示します（お問い合わせ: info@example.com） |

{% hint style="info" %}
お名前は省略せずに載せておくのがおすすめです。省略するのは住所と電話番号だけにしておくと、見た人も安心できます。連絡先の欄には、メールアドレスやお問い合わせフォームを添えておくと親切です。
{% endhint %}

## この書き方をするときの約束

* **実際に請求が来たら、すぐに伝えてください。** メールなどで、住所と電話番号を遅れずに知らせる必要があります。「開示します」と書いたのに返事をしないのは認められません。
* **伝える住所は、実際に連絡が届く住所です。** 自宅か、ご自身の名義で契約しているバーチャルオフィスなどの住所を伝えます。
* **商品を発送する場合は、送り状や納品書に実際の住所が必要です。** ページで省略していても、発送の場面では省略できません。

## メールを送る場合は別です

**メッセージ & ワークフローでメルマガや自動メールを送る場合は、この方法は使えません。** メールには別の法律で住所の表示が決められていて、「請求があれば開示」で省くことができないためです。

自宅の住所を出したくない場合の方法は、次の記事にまとめています。

→ [メール配信に必要な住所の設定（自宅住所を出したくない方へ）](../email-and-automation/business-address-for-email.md)
