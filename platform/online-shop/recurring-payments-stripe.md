# 毎月の支払いを、カードで受け取る（Stripe の準備）


月謝、月額の会費、ファンクラブ。こうした**毎月の支払いを、お客様のカードから自動で受け取る**には、決済サービスの Stripe（ストライプ）が必要です。PayPal は、1回ごとの支払い専用です。

この記事では、Stripe を使えるようにして、OpusBooster につなぐまでの流れを説明します。

## 決済サービスごとの、できること

| 決済サービス | 1回ごとの支払い | 毎月など、定期の支払い |
| --- | --- | --- |
| Stripe（カード） | できます | **できます** |
| PayPal | できます | できません |

PayPal で定期の支払いの商品を買えるように見えても、2回目からの請求は行われません。毎月の支払いを受け取りたい場合は、Stripe を使ってください。

## 先に用意するもの

Stripe は、申し込みのあとに、事業の内容を確認します。次のものを先に用意しておくと、途中で止まりません。

1. **あなたのサイト**（OpusBooster で作ったサイトで大丈夫です）。何を、いくらで提供しているかが分かるページがあること。
2. **特定商取引法に基づく表記**。日本では、この表記をサイトに載せていないと、Stripe を使えません。書き方は [特商法の設定マニュアル（個人事業主）](https://docs.opusbooster.com/platform/online-shop/tokushoho-setup-individual) ／ [（法人）](https://docs.opusbooster.com/platform/online-shop/tokushoho-setup-corporate) をご覧ください。
3. **本人確認の書類**（運転免許証、パスポートなど、公的な身分証）。
4. **売上を受け取る銀行口座**。
5. **お客様のカードの明細に出る名前**（半角の英字で5〜22文字。教室名や屋号のローマ字など）。

{% hint style="info" %}
**特定商取引法に基づく表記に、Stripe が求める項目**

販売する人の名前、所在地、電話番号、メールアドレス、責任者、追加でかかる料金、返品と返金の決まり、提供の時期、使える支払い方法、支払いの時期、価格（税込み）。個人の方は、所在地と電話番号を「請求があれば遅滞なく開示します」と書いて省略できます。くわしくは、[Stripe の説明](https://support.stripe.com/questions/how-to-create-and-display-a-commerce-disclosure-page?locale=ja-JP)をご覧ください。
{% endhint %}

## Stripe をつなぐ

Stripe のアカウントは、OpusBooster の画面から作り始められます。先に Stripe のサイトで登録しておく必要はありません。

1. 上のバーの「**ネットショップ**」を開き、左のメニューの「**設定**」を押します。
2. 「**決済**」のタブを開き、「決済方法」の右にある「**＋ 追加**」を押します。
3. 「決済方法を追加する」の一覧で、いちばん上の Stripe の「**接続**」を押します。Stripe の画面に移ります。
4. Stripe の画面（「Stripe の使用を開始する」）で、**メールアドレス**を入れて「**続ける**」を押します。
   - すでに Stripe のアカウントがある方: そのアカウントのメールアドレスを入れると、ログインに進みます。
   - はじめての方: 使いたいメールアドレスを入れると、新しいアカウントの作成に進みます。事業の情報、本人確認、銀行口座を、画面の案内に沿って入れます。
5. 終わると、OpusBooster の画面に戻ります。「決済」のタブの「決済方法」に Stripe が出ていれば、接続は完了です。

{% hint style="warning" %}
**一覧の「接続」は、使うものだけ押してください**

PayPal など一部の決済方法は、「接続」を押しただけで「決済方法」の一覧に追加されます。メールアドレスなどを入れていなければ、設定はされていません。間違えて追加したときは、その行の「設定」→「無効にする」で外せます。
{% endhint %}

Stripe の確認が終わるまで、実際の支払いを受け取れないことがあります。追加の書類を求めるメールが Stripe から届いたら、Stripe の管理画面で提出してください。

## 毎月の支払いの商品を作る

接続ができたら、毎月の支払いの商品を作ります。

1. 「ネットショップ」→「**商品**」→「商品を追加」を押します。
2. 値段の欄の「**サブスクリプション商品**」にチェックを入れます。
3. 「**請求回数**」と「**請求間隔**」を決めます。月謝なら、請求回数は「継続的な支払い」、請求間隔は「1 ヶ月」です。

くわしくは [商品の作成](https://docs.opusbooster.com/platform/online-shop/create-products) をご覧ください。

{% hint style="info" %}
**最初の1か月だけ、金額を変えたいとき**

お客様が自分で入力するディスカウントコードを使います。お客様が入力したコードは、1回目の支払いにだけ効きます。「自動的に適用されます」にチェックを入れた割引は、毎回の支払いに効きます。0円にはできません。作り方は [ファネルハブの次に足すもの](https://docs.opusbooster.com/platform/getting-started/after-funnel-hub) の「段1」をご覧ください。
{% endhint %}

## お客様に、はっきり伝えること

毎月の支払いは、申し込みのページに、次のことを本文と同じ大きさで書いてください。チェックアウトの画面に出るのは「◯円 / 月」のような短い表示だけで、次回からの請求の説明は出ません。

- 毎月いくら、いつ請求されるか
- 最初の1か月だけ金額が違う場合は、2か月目からの金額
- やめたいときの連絡先と、いつまでに連絡すればよいか

## 自分で1回、通して確かめる

案内を始める前に、自分で申し込んで確かめます。

- 申し込みのページから、支払いの完了まで進めるか
- 確認のメールが届くか
- 「ネットショップ」→「**サブスクリプション**」に、次回の支払いの日と金額が正しく出ているか

確かめたあと、自分の分の定期の支払いは止めておきます。止め方は [サブスクリプション管理](https://docs.opusbooster.com/platform/online-shop/subscription-management) をご覧ください。

## よくある質問

**PayPal しか使っていません。毎月の支払いは受け取れませんか**
自動では受け取れません。1回ごとに買ってもらう商品（1か月分、回数券など）にするか、Stripe を追加してください。

**Stripe の手数料は、いくらですか**
カードの支払いが成立するごとに、Stripe の手数料がかかります。初期費用や月額の費用はありません。最新の料率は、[Stripe の料金のページ](https://stripe.com/jp/pricing)をご覧ください。OpusBooster の販売手数料は、かかりません。

**売上は、いつ口座に入りますか**
Stripe の管理画面で、入金の周期（週ごと・月ごとなど）を選べます。最初の入金までは、数日かかります。

**お客様が、やめたいと言ってきたら**
「ネットショップ」→「サブスクリプション」で、その方の定期の支払いを止めます。くわしくは [サブスクリプション管理](https://docs.opusbooster.com/platform/online-shop/subscription-management) をご覧ください。
