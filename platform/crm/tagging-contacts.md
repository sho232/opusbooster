# 顧客のタグ付け

タグは、連絡先エリア内の顧客をセグメント化するのに最適です。

タグを作成するには、 \[連絡先]タブに移動し、下図のようにタグのアイコンを選択します。

<figure><img src="../../.gitbook/assets/image (10).png" alt=""><figcaption></figcaption></figure>

新しいタグを作成すると、タグリストに表示されます。また、プロフィールに特定のタグを追加しているすべての連絡先を表示できるようになります。

### 1人の連絡先にタグを付ける

1. **連絡先**の一覧から、タグを付けたい人を開きます
2. 「**タグの追加**」を押します
3. 新しく作るときは「**新しいタグを追加**」を押してタグの名前を入れ、「**送信**」を押します
4. 「**確認**」を押すと、その人にタグが付きます（「保存」のボタンはありません）

{% hint style="info" %}
**連絡先の一覧の「タグ」ボタンは、絞り込みではなくタグ付けのボタンです**

タグで連絡先を絞り込みたいときは「**フィルターを追加**」→「**タグ**」を使います。
{% endhint %}

{% hint style="warning" %}
**タグはそのままメールの送り先に選べません**

メールキャンペーンの宛先に選べるのはリストかセグメントだけです。タグが付いた人にだけ送りたいときは、先にそのタグで絞り込んだセグメントを作ります。手順は[メールキャンペーン](../email-and-automation/email-campaigns.md#send-by-tag)をご覧ください。
{% endhint %}

{% hint style="info" %}
チェックアウト、フォーム、トリガー自動化などのさまざまなウィジェットにタグを作成することもできます。タグ作成プロセスをスピードアップするのに役立ちます。
{% endhint %}
