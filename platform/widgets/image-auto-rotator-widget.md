# 画像オートローテーターウィジェット

複数の画像を、横に流れ続ける帯（マーキー）またはグリッドで表示するウィジェットです。実績写真、商品カット、取引先のロゴ、作品集などを、訪問者にクリックさせずにまとめて見せられます。

### このウィジェットが向いている場面

**動きが目に留まります。** 静止したギャラリーより、横に流れている方が視線を集めます。ページ上部や「導入企業」の帯として使うと効果的です。

**狭いスペースにたくさん載せられます。** 画像が縦に積み上がらず横に流れるので、少ない高さで多くの写真を見せられます。

**用途を選びません。** 商品ギャラリー、ポートフォリオ、ロゴの一覧、雰囲気を伝える写真など、幅広く使えます。

**手間がかかりません。** スライダーを組み立てる必要がなく、画像をアップして表示方法を選ぶだけです。

### 表示方法は2種類

**マーキー（流れる）**

画像が横方向に途切れなく流れ続けます。ロゴの帯や、背景的に写真を見せたいときに向いています。

**グリッド**

画像が固定の格子状に並びます。動きのない、落ち着いたギャラリーになります。

### 設定方法

1. **「+ 追加」**&#x3067;画像を1枚ずつ足していきます
2. ハンドルを**ドラッグして並び順**を変えられます
3. ゴミ箱アイコンで画像を削除できます

### 設定項目

| 項目 | 内容 |
|---|---|
| 見出し | ギャラリーの上に表示するラベル（例:「導入いただいている企業さま」） |
| 文字スタイル | 見出しの書体・サイズの設定 |
| グレースケール | 通常は白黒で表示し、カーソルを乗せると色が出ます。ロゴを並べるときに向いています |
| クリックで拡大 | 訪問者が画像をクリックすると大きく表示されます |
| 画像の高さ | 1枚あたりの表示サイズ |
| 流れる速さ | マーキーの場合のスクロール速度 |
| 角の丸み | 画像の四隅を丸くします |
