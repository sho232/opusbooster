# スタッフや外注さんに入ってもらう（管理者の追加）

サイトの更新を外注さんに頼むたびに、自分のパスワードを教えていませんか。教えたパスワードは、変えるまで使えてしまいます。

OpusBoosterでは、**1人に1つ、その人自身の入り口を作れます**。頼むのをやめたら、その人の入り口だけを消せます。

## 管理者の画面はどこにあるか

[ダッシュボード](https://opusbooster.com/me/dashboard)の中ほどにあるタブ（概要・管理者・請求・アフィリエイト/リファラル・アカウント）から「**管理者**」を開きます。

画面には次のように書かれています。

> プロジェクトへのアクセスを管理。新しい管理者には招待メールが届きます。

管理者は**プロジェクトごと**です。招待した人が入れるのは、いま開いているプロジェクトだけです（[プロジェクトを切り替える](switch-projects.md)）。

## 管理者を追加する

1. 「**管理者を追加**」を押します
2. 「**変更する**」で、触れる範囲を選びます。**すべてのサイト＆ファネル**か、**1つのサイト**を選べます
3. 触れる場所にチェックを入れます

| まとまり | 選べる場所 |
| --- | --- |
| ウェブサイトビルダー | ページビルダー・ブログ・ポートフォリオ・ネットショップ・ドメイン |
| CRM | CRM＆メンバー・メッセージ |
| コミュニティ | サークル・メンバー・モデレーション |
| 管理画面 | 解析 |
| プロジェクトアクセス | 請求・チームメンバー・プロジェクトでより多くのウェブサイト＆ファネルを作成する機能 |

4. その人の**メールアドレス**を入れて、「**招待メールを送信**」を押します

{% hint style="info" %}
**頼む仕事に必要な場所だけにチェックを入れましょう**

たとえばページの文章の更新だけなら「ページビルダー」だけで足ります。「請求」や「チームメンバー」は、お金や人の出入りに関わるので、本当に必要なときだけにします。
{% endhint %}

## 管理者を外す・権限を変える

管理者の一覧で、その人の行の右にある**歯車のアイコン**を押すと、次のメニューが出ます。

* **権限を更新**：触れる場所を変える
* **管理者を削除する**：その人の入り口を消す
* **プロジェクトオーナーを作成する**：その人をプロジェクトのオーナーにする

## 自分のパスワードを変える

これまでパスワードを教えていた人がいたら、その人を管理者として招待したうえで、**自分のパスワードを変えておきましょう**。

1. 同じタブの並びにある「**アカウント**」を開きます
2. 「**新しいパスワード**」と「**パスワード確認**」に同じものを入れます（6文字以上）
3. 「**変更内容を保存**」を押します
