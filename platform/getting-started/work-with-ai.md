# AI に操作を手伝ってもらう


OpusBooster のサイトづくりは、AI に手伝ってもらえます。「私の教室のウェブサイトを作って」と頼むと、AI があなたに必要なことを聞き、テンプレートを選び、文言を差し替えていきます。

ただし、何も渡さずに頼むと、AI は白紙からページを組もうとします。見た目は整っても、来た人を登録や申し込みへ案内する形にはなりにくく、保存のしかたなど OpusBooster 特有の注意も知りません。そこで、AI に読ませる資料を用意しました。先にこれを渡してから頼んでください。

## AI にできること、あなたがやること

| AI に任せられること | あなたがやること |
| --- | --- |
| どのテンプレートから始めるかの提案 | 登録とログイン（メールアドレスとパスワードの入力） |
| 見出しや紹介文の下書き | 写真・プロフィール・料金・お客様の声など、事実の提供 |
| 文言や写真の差し替え、ページの追加、メニューの設定 | メールの送信、配信、公開の告知などの承認 |
| フォームやリストの設定の確認 | サイトやファネルそのものの削除 |
| 公開ページを開いての確認と報告 | 最後に自分の目で読むこと |

管理画面の操作まで代わりに進められるのは、ブラウザを操作できる AI です。ブラウザを操作できない AI でも、同じ資料を渡せば、手順を1つずつ案内する相談役として使えます。

{% hint style="warning" %}
**お客様の声や実績の数字は、AI に作らせないでください**

テンプレートの人物・数字・お客様の声・料金は、すべて見本です。資料を読んだ AI は、あなたに聞いて事実に置き換え、分からない所を作り話で埋めません。「それらしく書いておいて」と頼むのも避けてください。あなたの名前で出るページです。
{% endhint %}

## 資料の渡し方（2通り）

### A. ファイルを渡す（どの AI でも使えます）

1. 下の資料のファイルをダウンロードします。

{% file src="../../.gitbook/assets/opusbooster-ai-pack.md" %}

2. 使っている AI に、そのファイルを添付します。
3. ファイルの最初にある「コピペ用指示文」を、そのまま貼って送ります。
4. 続けて「確認の一言」を送り、AI にルールを復唱させます。ずれていたら、その場で直してもらいます。

会話をまたいで覚えていられない AI では、新しい会話のたびに、ファイルを渡し直してください。

### B. スキルを入れる（Claude を使っている方）

Claude には、決まった仕事のやり方を覚えさせておく「スキル」という仕組みがあります。一度入れておくと、OpusBooster の話になったときに自動で読み込まれ、毎回ファイルを渡す必要がありません。

**Claude のアプリ（ブラウザ版・デスクトップ版）の場合**

1. 下のスキルのファイル（ZIP）をダウンロードします。解凍はしません。

{% file src="../../.gitbook/assets/opusbooster-site-builder.zip" %}

2. Claude の設定（Settings）の「Capabilities」を開き、「Code execution and file creation」（画面によっては「Create and edit files」）がオンになっているのを確かめます。
3. 「Customize」→「Skills」を開きます。
4. 「＋」を押し、「Create skill」→「Upload a skill」を選んで、ダウンロードした ZIP を選びます。
5. 一覧に「opusbooster-site-builder」が出て、オンになっていれば完了です。

スキルは、無料プランを含むどのプランでも使えます。会社や団体の契約で使っている場合は、管理者の設定でスキルの追加が止められていることがあります。画面の項目の名前は、Claude の更新で変わることがあります。見当たらないときは、[Claude の公式ヘルプ](https://support.claude.com/ja/articles/12512180)を確かめてください。

**Claude Code の場合**

1. 上の ZIP をダウンロードして、解凍します。「opusbooster-site-builder」というフォルダができます。
2. そのフォルダを、ホームフォルダの中の `.claude/skills/` に入れます（`~/.claude/skills/opusbooster-site-builder/SKILL.md` という並びになります）。
3. Claude Code で `/skills` と入力して、一覧に出ていれば完了です。再起動は要りません。

## 最初の頼み方

資料を渡したら、やりたいことをそのまま頼みます。

- 「私の活動のウェブサイトを作りたいです。どのテンプレートから始めるかを提案してください。」
- 「自己紹介ページを作りました。次に足すページを1枚選んで、下書きを作ってください。」
- 「YouTube に上げた演奏動画を、サイトに並べたいです。」
- 「無料プレゼントの登録の流れで、まだ足りないものを確かめてください。」

AI は最初に、活動の種類、提供しているものと料金、手元にある素材を聞いてきます。そのうえで、ページが全部そろったテンプレート（ファネルハブ）から始めるか、自己紹介ページから1枚ずつ足すかを提案します。進める順番は、[自己紹介ページから始めて、サイトを育てる](https://docs.opusbooster.com/platform/getting-started/grow-from-first-page) と同じです。

## 管理画面の操作を任せるとき

- **ログインは自分で**: AI にメールアドレスやパスワードを渡さないでください。ログイン画面が出たら、あなたがログインしてから、続きを頼みます。
- **同じサイトを、同時に2か所で開かない**: AI が作業している間は、自分でも同じサイトの編集画面を開いて保存しないでください。古い画面で保存すると、AI の変更が巻き戻ることがあります。
- **報告は、公開ページで確かめてもらう**: 「できました」と言われたら、「公開ページを開いて確かめましたか。確かめていない所はどこですか」と聞いてください。資料を読んだ AI は、確かめた所とまだの所を分けて報告します。
- **送る・消すは、あなたが決める**: メールの送信、自動のメールをオンにすること、ページや作品の削除は、AI があなたに確認してから行います。サイトやファネルそのものの削除は、あなたが自分で行ってください。

## うまくいかないとき

| 困ったこと | 確かめる所 |
| --- | --- |
| AI が白紙からページを作ろうとする | 資料を渡したか。渡してあるなら「資料の『最初の分かれ道』から始めてください」と伝える |
| 次の日になったら、決まりを忘れている | ファイル版は、会話ごとに渡し直す。Claude ならスキル版を入れる |
| 「できました」と言われたが、公開ページが変わっていない | 「公開ページを開いて確かめてください」と頼む。保存されていないことがある |
| 書いた覚えのない文に変わっている | 文字の編集中に、AI の文章作成のボタンが押された可能性。すぐなら「元に戻す」で戻せる |
| ログイン画面で止まる | あなたがログインしてから、続きを頼む |
