# プロジェクトを切り替える

「作ったはずのサイトが見当たらない」「ログインしたら見覚えのない画面だった」というときは、**別のプロジェクトを開いている**可能性があります。消えたわけではありません。

## プロジェクトとは

プロジェクトは、ウェブサイトやファネルをまとめて入れておく箱です。1つのアカウントで**複数のプロジェクトを持てます**。

ダッシュボードは常に**そのうち1つだけ**を表示しています。そのため、目的のサイトが別のプロジェクトに入っていると、探しても見つかりません。

複数のプロジェクトを持つことになる場面は、たとえばこんなときです。

* 別のプロジェクトにスタッフとして招待された
* 新しい企画やキャンペーン用に、別途プロジェクトが用意された
* 用途ごとにご自分で分けて作った

## 切り替える手順

1. [ダッシュボード](https://opusbooster.com/me/dashboard)を開きます
2. 画面の左側にある「**プロジェクトの切り替え**」をクリックします
3. 権限のあるプロジェクトの一覧が表示されるので、開きたいものをクリックします

これで表示が切り替わります。**元のプロジェクトは残っています**。いつでも同じ手順で戻れます。

{% hint style="info" %}
「プロジェクトの切り替え」は、左側のプロジェクト名（「Main」など）とウェブサイト・ファネルの件数が並んでいるあたりにあります。ビルダーの画面を開いている場合は、先に左上の「ダッシュボード」でダッシュボードに戻ってください。
{% endhint %}

## 見分け方

一覧に似た名前が並んでいて迷うときは、切り替えたあとにウェブサイトの数とサイト名を見てください。目的のサイトが入っていれば、そのプロジェクトで合っています。

## よくある質問

**Q. 切り替えたら、前のプロジェクトのデータはどうなりますか**

そのままです。表示を切り替えているだけなので、中身には何も起きません。

**Q. 一覧に目的のプロジェクトが出てきません**

そのプロジェクトへの権限がアカウントに付いていない可能性があります。招待された側の場合は、招待した方に権限の状態を確認してもらってください。それでも解決しない場合は[サポート](../../extra/getting-support.md)からご連絡ください。

**Q. プロジェクトごとに料金はかかりますか**

プランはプロジェクト単位です。詳しくは[料金ページ](https://opusbooster.com/pricing)をご確認ください。
