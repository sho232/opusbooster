# サイトができたあとに、次に足すもの


拠点サイト（活動の入口が全部そろったサイト）ができて、無料プレゼントの登録が入り始めたら、**次に作るのは、段1の「お試し入会」だけです。** その先に段2・段3がありますが、一度に作る必要はありません。1つの段が回り始めてから、次の段へ進みます。段1だけでも、活動は十分に成り立ちます。

## 全体の流れ

| 段 | 足すもの | 来た人にしてほしいこと |
| --- | --- | --- |
| 土台 | 拠点サイトと、無料プレゼントの登録の流れ | メールアドレスの登録 |
| 1 | 続けて通ってもらう形と、お試し入会 | 1か月、試してみる |
| 2 | まとめて伝える場（説明会・ウェビナー・数日間の体験企画） | 参加の申し込み |
| 3 | 個別のご相談 | ご相談の予約 |

どの段も、目的は同じです。**毎月続けてくれる人を、少しずつ増やすこと。** 単発の申し込みを毎回ゼロから集めるより、続けてくれる人が積み上がるほうが、活動は安定します。

### 段をつなぐのは、メールです

どの段でも、案内を届けるのはメール（と LINE）です。登録してくれた人に、定期的に便りを送ってください。週に1回からでかまいません。演奏や教室の近況、練習の小さなコツ、次の予定。ふだんから届いていれば、お試し入会や説明会の案内も、自然に読んでもらえます。便りが止まると、3つの段は別々のページのままで、次の段へ上がる道ができません。

土台がまだの方は、先に [自己紹介ページから始めて、サイトを育てる](https://docs.opusbooster.com/platform/getting-started/grow-from-first-page) をご覧ください。

## 段1. 続けて通ってもらう形と、お試し入会

最初に足すのは、「続けてもらう形」です。教室なら月謝、演奏家なら月額の会員やファンクラブがこれにあたります。月謝制の教室は、すでにこの形を持っています。

そのうえで、**お試し入会**のページを足します。体験レッスンや無料プレゼントで関心を持った人に、「まず1か月だけ」と言える入口です。

- 見出しの主役は、入会の特典です（ここでしか手に入らないものを3つ）。
- 最初の1か月の金額と、2か月目からの金額、やめ方を、同じ大きさで書きます。お試しの1か月は0円にできないので、ページに「無料」とは書きません。
- 「続けるかどうかは、1か月後に決めてください」と伝えます。

作り方は、「ページ & ポップアップ」→「新しく追加する」→「ページ」で、カテゴリー「拠点サイト」の中の、「お試し入会」と書かれたひな形を選びます。特典・金額・定員・やめ方を、自分のものに差し替えてください。見本の教室・金額・日付は、すべて架空です。

{% hint style="info" %}
**最初の1か月だけ金額を変える方法**

定期の支払いの商品に、お客様が自分で入力するディスカウントコードを組み合わせます。お客様が入力したコードは、1回目の支払いにだけ効きます。「自動的に適用されます」にチェックを入れた割引は、毎回の支払いに効くので、お試しには使いません。0円にはできません（支払い方法が登録されず、2回目から請求できなくなります）。毎月の支払いをカードで受け取るための準備は、[毎月の支払いを、カードで受け取る（Stripe の準備）](https://docs.opusbooster.com/platform/online-shop/recurring-payments-stripe) をご覧ください。
{% endhint %}

**特典の決め方**（3つの問い）

1. それは、ここでしか手に入りませんか
2. それは、欲しくなるものですか（手に取れる、耳に残る、名前が入る）
3. それは、続きが気になるものですか（全部を渡さない。1曲目だけ、最初の1回だけ）

レッスンや講座を丸ごと特典にするのは、おすすめしません。それは、続けてもらう形のほうの中身です。

**対面のレッスンの方へ**: 席には限りがあります。お試し入会の定員を先に決めて、ページに書いてください。お試し中の方の席も、数に入れます。

**すでに説明会や体験会を開いている方へ**: 新しい場を作る必要はありません。いまある申し込みのお礼のページに、お試し入会の案内を置いてください。これは段1のうちにできます。

**次の段へ進む目安**: お試し入会の申し込みが、毎月、同じ流れで入るようになったら。

## 段2. まとめて伝える場

次に足すのは、関心のある人に、まとめて伝える場です。説明会、オンラインのウェビナー、数日間の体験企画などです。1人ずつ説明していたことを、一度に伝えられます。

この場には、もう1つ役目があります。**参加した人は、お試し入会を続けやすくなります。** あなたの考え方と進め方を先に知ってもらえるからです。申し込みに至らなかった人にも、その理解は残ります。

- 申し込みの直後のお礼のページで、お試し入会を案内します（次の一歩は、1つだけ）。
- 場の最後に、まとまった形の申し込み（半年分・1年分など）を案内します。

作り方は、[ウェビナー](https://docs.opusbooster.com/funnel-designs/types-of-funnels/webinar) と [チャレンジファネル](https://docs.opusbooster.com/funnel-designs/types-of-funnels/challenge-funnel) をご覧ください。

**人を集めるときは、案内を1つに絞ります。** 場を開くと決めたら、その期間は、メールも SNS も、この場の案内だけにします。ほかのお知らせと並べると、どれも読まれません。

回数は、多くなくてかまいません。3か月に1回、同じ内容をていねいに直しながら続けるほうが、毎回新しい企画を作るより成果につながります。

**次の段へ進む目安**: 同じ内容の場を何度か開いて、毎回、申し込みが入るようになったら。

## 段3. 個別のご相談

最後に足すのは、金額の大きい申し込みのための、個別のご相談です。個人レッスンの長期コース、制作の依頼、出張演奏の年間契約などが向いています。

- いきなり料金表を見せず、先に動画や文章で考え方を伝えます。
- 申し込みフォームで、状況を聞きます。
- そのうえで、日時を決めてお話しします。

発表会や公開レッスンのように、何人かが集まる場をすでに持っている方は、その場のあとに個別のご相談を案内するのも自然です。

作り方は、[申込式ハイチケットファネル](https://docs.opusbooster.com/funnel-designs/types-of-funnels/application-funnel) と [予約ブッキングファネル](https://docs.opusbooster.com/funnel-designs/types-of-funnels/appointment-booking) をご覧ください。

## よくあるつまずき

| つまずき | こうします |
| --- | --- |
| 3つの段を、同時に作り始める | 段1だけを作って、案内を始める。回り始めてから次へ |
| 入口を増やしすぎる | 無料プレゼントは1つ、お試し入会のページも1つ。直すのは、中身の特典 |
| 段を飛ばして、いきなり個別のご相談から始める | 続けてもらう形が無いと、毎回の申し込みを一から集め続けることになる |
| 新しい企画を、次々に作る | 同じ流れを繰り返して、少しずつ直す |

## AI に手伝ってもらう場合

AI に渡す資料には、この順番も入っています。「次に何を足せばいいですか」と聞くと、いまの段を確かめてから、次の一歩を1つ提案します。くわしくは [AI に操作を手伝ってもらう](https://docs.opusbooster.com/platform/getting-started/work-with-ai) をご覧ください。
