# ムームードメインでレコードを追加する

## この手順を使う人

ドメインの**ネームサーバーがムームーDNS**（`muumuu-domain.com` を含む名前）になっている方です。ムームードメインで買っていても、他社のサーバーで運用している場合は、**その会社の手順**を使ってください。→ [どこで管理されているか調べる](where-is-my-domain.md)

## 追加する行を決める

やりたいことに合わせて、A・B のどちらか、または両方の行を用意します。同じ画面で足せるので、両方やるなら一度で済みます。

**A. サイトを自分のドメインで表示する（2行）** — 値は OpusBooster の「**ウェブサイト/ファネルの設定 → ドメイン**」画面のもの。→ [カスタムドメインの接続](../custom-domain.md)

| 種別 | サブドメイン | 内容 |
|---|---|---|
| **A** | 空欄 | 画面に表示された数字（IPアドレス） |
| **CNAME** | `www` | 画面に表示された値 |

**B. メールを自分のドメインから送る（2行）** — 値は「**メール & オートメーション → 設定 → ドメインと送信者**」画面のもの。→ [メールドメインの接続](../../email-and-automation/email-domain-connection.md)

| 種別 | サブドメイン | 内容 |
|---|---|---|
| **TXT** | 空欄 | 画面に表示された長い文字列 |
| **CNAME** | `def._domainkey` | `client._domainkey.app-sources.com` |

{% hint style="warning" %}
**A（サイト用）を入れると、サイトの表示先が OpusBooster に切り替わります。** 元からある「サブドメインが空欄の A」や「www」の行がある場合は、足すのではなく**値を書き換え**ます（A が2つあると繋がりません）。B（メール用）は足すだけで、今あるものは変わりません。
{% endhint %}

## 手順

1. [ムームードメインのコントロールパネル](https://muumuu-domain.com/) にログインします。
2. 左のメニューの「**ドメイン操作**」→「**ムームーDNS**」を押します。
3. 対象ドメインの右の「**変更**」（まだ使っていない場合は「**利用する**」）を押します。
4. ページの下の「**カスタム設定**」を押します。
5. 「**設定2**」の「**設定を追加する**」を押し、上で決めた行を **1行ずつ**入れます。
   * **サブドメイン**: 表のとおり（TXT と A は空欄でドメイン自体を表します。CNAME は `www` / `def._domainkey` が必須で、あとの「.あなたのドメイン」は自動で付きます）
   * **種別**: 表の「種別」
   * **内容**: OpusBooster の画面からコピーボタンで貼る
6. 「**セットアップ情報変更**」を押して保存します。

<!-- 📷 スクショ: 手順2〜3 「ドメイン操作」→「ムームーDNS」→「変更」 -->
<!-- 📷 スクショ: 手順5 「設定2」に行を入れた状態 -->

{% hint style="info" %}
「**設定1**」は、ロリポップなど GMOペパボのサービスと一緒に使うときの欄です。今回の行は「**設定2**」に入れます。「設定1」は触らなくて大丈夫です。
{% endhint %}

{% hint style="warning" %}
**「カスタム設定」を一度やめると、登録したレコードは全部消えます。**
あとで「簡単設定」に戻すと、今回入れた行も消えて、サイトが表示されなくなったりメールが送れなくなったりします。ムームーDNS はカスタム設定のまま使ってください。
{% endhint %}

## 追加したあと

* **サイト用**: OpusBooster の「ドメイン」画面で接続の状態を確認します。ムームードメインの反映は1時間ほど、最長 48 時間。→ [カスタムドメインの接続](../custom-domain.md)
* **メール用**: 「ドメインと送信者」で「**ステータスを更新**」を押します。1時間ほど、長くて 48 時間で「確認済み」。→ [反映を待つ・うまくいかないとき](../../email-and-automation/email-domain-connection.md#not-verified)
