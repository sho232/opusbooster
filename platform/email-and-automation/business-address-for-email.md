# メール配信に必要な住所の設定（自宅住所を出したくない方へ）

## この設定は何のため？

メッセージ & ワークフローでメルマガ（キャンペーン）や自動メール（オートメーション）を初めて作るとき、**「ブランド詳細」として事業者名と住所の入力を求められます。** ここに入れた内容は、送るメールの下の方に自動で表示されます。

自宅でレッスンをしている先生などは「自宅の住所を全員に送るのは避けたい」と思われるはずです。この記事では、その場合の進め方を案内します。

## なぜ住所が必要なの？

お知らせや案内などの宣伝を含むメールには、**送り主の名前と住所を載せることが法律（特定電子メール法）で決められています。** 相手が自分から登録してくれた人でも同じです。

{% hint style="warning" %}
**ウェブページの特商法の表記とは扱いが違います。** 特商法の表記は「請求があれば遅滞なく開示します」で住所を省けますが、メールにはこの省き方がありません。→ [特商法の表記で住所を載せずに済ませる方法](../online-shop/hide-business-address.md)
{% endhint %}

## ブランド詳細に入れる内容

* **事業者名** — 送り主の正式な名前を入れます。個人の方は本名、会社の方は会社名です。教室名や屋号だけでは、送り主を表示したことになりません。教室名も見せたいときは「山田 花子（やまだピアノ教室）」のように並べて書きます。
* **住所** — 実際に郵便物が届く住所を入れます。自宅を出したくない方は、次の「自宅の住所を出したくない場合」を見てください。

## 自宅の住所を出したくない場合

**バーチャルオフィス（住所を貸してくれるサービス）を契約して、その住所を入れる方法がおすすめです。** 届いた郵便物を自宅へ転送してもらえるので、メールを見た人から郵便が来ても受け取れます。

### 選ぶときのポイント

1. **ご自身の名義で契約する** — 住所はあなたの連絡先として載せるものです。家族や知人、ほかの会社が契約している住所を借りて載せることはできません。
2. **郵便物を受け取って知らせてくれるか** — 住所を貸すだけで郵便を受け取らないプランもあります。郵便の到着連絡か転送があるプランを選んでください。
3. **料金は「月額＋転送料」の合計で比べる** — 住所だけのプランは月数百円からありますが、郵便転送を付けると月1,000〜3,000円ほどになることが多いです。

代表的なサービスには、DMMバーチャルオフィスやGMOオフィスサポートなどがあります。プランと料金は変わることがあるので、申し込む前に各社の公式サイトで確認してください。

### 設定の流れ

1. バーチャルオフィスを申し込み、本人確認を済ませる
2. 使える住所が届いたら、OpusBooster のブランド詳細に入力する
3. 自分あてにテストメールを送り、メールの下の方に名前と住所が正しく出ているか確認する

{% hint style="info" %}
**ウェブページの特商法の表記にも、同じ住所を載せられます。** 「請求があれば開示」の書き方にしている場合も、請求が来たときはこの住所を伝えれば大丈夫です。
{% endhint %}

{% hint style="warning" %}
この記事は一般的な考え方のご案内です。ご自身の事業に当てはまるかの最終的な判断は、弁護士などの専門家にご確認ください。
{% endhint %}
