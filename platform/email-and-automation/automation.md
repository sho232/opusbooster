# オートメーション概要

オートメーションは、コンバージョンを増加させ、バックグラウンドで自動的に購読者情報を更新しながら、時間を節約するために本当に役立ちます。

オートメーションの組み合わせは何千通りもありますが、ここでは一部のユーザーが自動化しているものをご紹介します。

* 電子書籍のダウンロード情報を送信
* フォームに入力された際に、ウェルカムメールを送信
* 顧客情報の更新
* ステップメールの送信
* コースのオンボーディング
* ウェビナー登録後、セールスファネルにリンクしたメールの送信
* コースコンテンツの送信
* ビジネス最新情報の送信
* ニュースレター
* などなど...

### オートメーションフローの基礎知識

オートメーションは、3つの基本要素から構成されています。

* **トリガー >** ウェブサイトを訪れた人、メールを開いた人、情報を更新した人など、さまざまな条件をきっかけとしてオートメーションフローを開始できます。
* **条件分岐 >** 複雑なオートメーションの作成も、「もし〜なら」というシンプルな機能で個々のオートメーションルールを作成することも可能です。
* **アクション >** 電子書籍を送る、情報を更新する、あるいは自動メールキャンペーンを送信するなど、さまざまなアクションを実行できます。

### 動かす前に確かめること

{% hint style="warning" %}
**メールドメインを接続していないと、オートメーションをオンにできません**

オンのスイッチを押すと一瞬オンに見えますが、画面を開き直すとオフに戻っています。先に[メールドメインの接続](email-domain-connection.md)を済ませてください。フローを組んで保存しておくところまでは、接続の前でもできます。
{% endhint %}

* **メール送信のステップは、送信者名と送信者メールを入れないと追加されません。** 空のまま閉じると、ステップが消えています。
* **メールの本文を編集する画面は、Escape を押すと保存されずに閉じます。** 右上の「**保存**」を押してから閉じ、最後にフロー右上の「**保存**」も押してください。
* 遅延の単位は「日間」「時間」「分」から選べます。動きを確かめるときは「分」にして自分で登録し、届いたら本来の日数に戻して保存すると早く確かめられます。
* **トリガーの設定を開いたあとは、Escape を2回押して閉じます。** 1回目はトリガーの一覧に戻るだけです。パネルが閉じ切る前にフロー右上の「**保存**」を押しても保存されません。

### 相手によって出し分ける（条件分岐）

「買ってくれた人には、催促のメールを送らない」のように、相手によって送るものを変えたいときは「**If / Else**」を使います。

* **「If / Else」は、フローのいちばん下にだけ置けます。** 途中の「＋」には出てきません。出し分けたいメールは、分かれたあとの「はい」「いいえ」の先に置きます。
* **判定は、その人が分かれ道まで来たときの状態で行われます。** オートメーションが始まったあとに付いたタグも反映されます。たとえば14日間の案内の途中で申し込んだ人は、最後の分かれ道に来た時点で「申込済み」のタグがあれば「はい」の側へ進みます。
* 条件は「**フィルターを追加**」から選びます。タグ、購読者リスト、グループなどが使えます。
* 「**OR条件の追加**」を押すと、「どちらかに当てはまる人」をまとめて「はい」の側へ送れます。

<details>

<summary>途中で止めるか、最後だけ分けるか</summary>

出し分けの方法は2つあります。

* **目標（ゴール）を使う** … 目標に達した人は、その時点でオートメーションから外れます。残りのメールは1通も届きません。「申し込んだら、以降の案内は全部いらない」というときに向いています。
* **いちばん下に「If / Else」を置く** … 途中のメールは全員に届け、最後のメールだけを出し分けます。「使い方の案内は最後まで届けたいが、期限のお知らせは申込済みの人には送りたくない」というときに向いています。

</details>

<details>

<summary>分かれ道が思ったとおりに動くか確かめる</summary>

本番のオートメーションを動かす前に、確かめ用のオートメーションを1本作ると数分で確かめられます。

1. トリガーを「タグが追加される」にして、確かめ用のタグを選びます。
2. 遅延を「分」で数分にします。
3. その下に「If / Else」を置き、条件に別の確かめ用のタグを選びます。
4. 「はい」と「いいえ」の両方に、日数の違う遅延を1つずつ置きます。
5. オンにして、自分の連絡先に1つ目のタグを付けます。遅延に入ったのを見てから、2つ目のタグを付けます。
6. 遅延が明けたあと、どちらの側の遅延に「1 待機」と出ているかを見ます。

確かめ終わったら、確かめ用のオートメーションはオフにするか削除し、タグも連絡先の設定から削除しておきます。

</details>

### きっかけを2つ以上にする

トリガーは「**新規トリガーの追加**」で2つ以上置けます。並べたトリガーは「OR」でつながり、どれか1つに当てはまった時点でオートメーションが始まります。

たとえば「登録フォームから入った人」と「別の経路で申し込み、あとからタグが付いた人」の両方に、同じ案内を届けられます。

* 「リストに追加」と「タグが追加される」のように、種類の違うトリガーも並べられます。
* 「タグが追加される」のトリガーは、タグが付いてから始まるまでに少し時間がかかります。手元で確かめたときは約1分でした。まとめて多くの人にタグを付けたときは、数分かけて順に始まります。
* オートメーションが動くのは、購読中の連絡先だけです。

### メモの追加

メモ機能を選択すると、オートメーションフローの各ステップにおいて、管理者やチームメンバーが役立つメモを残すことができます。これは、ステップ情報を思い出すのにとても便利で、チームに完了させるための指示を追加するだけです。書いて、保存して、ピン留めしてください。

### アナリティクス

開封率、誰が何をクリックしたか、何人がオートメーションを完了したか、をリアルタイムに確認できます。

<figure><img src="../../.gitbook/assets/スクリーンショット 2022-12-26 20.23.25.png" alt=""><figcaption></figcaption></figure>

### 目標設定

目標を設定することで、自動化が成功したかどうかを判断することができます。購読者が特定のゴールに到達すると、OpusBoosterそれを成功とみなし、アナリティクスダッシュボードにゴールとして登録します。設定したゴールに到達したユーザーは、そのオートメーションから削除されます。
