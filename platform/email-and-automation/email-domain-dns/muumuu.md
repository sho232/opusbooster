# ムームードメインでレコードを追加する

## この手順を使う人

ドメインの**ネームサーバーがムームーDNS**（`muumuu-domain.com` を含む名前）になっている方です。ムームードメインで買っていても、他社のサーバーで運用している場合は、**その会社の手順**を使ってください。→ [どこで管理されているか調べる](where-is-my-domain.md)

## 用意するもの

OpusBooster の「**ドメインと送信者**」画面に表示された2つのレコード。→ [メールドメインの接続](../email-domain-connection.md)

## 手順

1. [ムームードメインのコントロールパネル](https://muumuu-domain.com/) にログインします。
2. 左のメニューの「**ドメイン操作**」→「**ムームーDNS**」を押します。
3. 対象ドメインの右の「**変更**」（まだ使っていない場合は「**利用する**」）を押します。
4. ページの下の「**カスタム設定**」を押します。
5. 「**設定2**」の「**設定を追加する**」を押し、**1つ目（TXT）**を入れます。
   * **サブドメイン**: 空欄のまま（TXT は空欄でドメイン自体を表します）
   * **種別**: `TXT`
   * **内容**: OpusBooster に表示された長い文字列を、コピーボタンで貼る
6. もう一度「**設定を追加する**」を押し、**2つ目（CNAME）**を入れます。
   * **サブドメイン**: `def._domainkey`（CNAME はここが必須です。あとの「.あなたのドメイン」は自動で付きます）
   * **種別**: `CNAME`
   * **内容**: `client._domainkey.app-sources.com`
7. 「**セットアップ情報変更**」を押して保存します。

<!-- 📷 スクショ: 手順5〜6 「設定2」に TXT / CNAME を入れた状態 -->

{% hint style="info" %}
「**設定1**」は、ロリポップなど GMOペパボのサービスと一緒に使うときの欄です。今回の2つは「**設定2**」に入れます。「設定1」は触らなくて大丈夫です。
{% endhint %}

{% hint style="warning" %}
**「カスタム設定」を一度やめると、登録したレコードは全部消えます。**
あとで「簡単設定」に戻すと、今回入れた2つも消えて、メールが送れなくなります。ムームーDNS はカスタム設定のまま使ってください。
{% endhint %}

## 追加したあと

OpusBooster の「ドメインと送信者」に戻り、「**ステータスを更新**」を押します。ムームードメインの反映は**1時間ほど**かかります。長くて 48 時間で「**確認済み**」になります。→ [反映を待つ・うまくいかないとき](../email-domain-connection.md#not-verified)
