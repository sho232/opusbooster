# 音楽家・教室のための使用例

ファネルの型は種類が多く、説明だけを読んでも「自分の場合はどれなのか」が見えにくいものです。この記事では、音楽教室の先生と、演奏家・作曲家のそれぞれについて、型ごとの使い方を並べました。

ここに挙げるのは、使い方を思い描くための例です。そのまま真似る必要はありません。自分の活動に近い行を見つけて、言葉を置き換えてみてください。

### 最初の1本を選ぶ

迷ったら、いまいちばん欲しいもので選びます。

| いま欲しいもの | 最初の1本 |
| --- | --- |
| 連絡先(メールやLINEの読者) | [リードジェネレーション](lead-generation.md) |
| 体験レッスンや相談の予約 | [予約ブッキングファネル](appointment-booking.md) |
| 低価格の教材や楽譜の、最初の売上 | [トリップワイヤーファネル](tripwire-funnel.md) |
| 講座やオンラインレッスンの申し込み | [ウェビナー](webinar.md) |
| SNSのプロフィールに置く入口 | [ヒーロー](hero.md) |

価格帯と段階から選びたいときは、[ファネルの種類一覧(バリューラダー別ガイド)](value-ladder-guide.md)をご覧ください。

### 音楽教室の先生の場合

| 型 | 使い方の例 |
| --- | --- |
| [リードジェネレーション](lead-generation.md) | 「大人の初心者が最初の1か月でやる練習メニュー」のPDFを、登録と引き換えに渡す |
| [オプトイン](opt-in.md) | 教室だよりの読者登録。発表会やレッスンの空き状況を届ける |
| [アスクキャンペーンファネル](ask-campaign-funnel.md) | 新しい講座を作る前に「両手で弾く練習で、いちばん困っていることは？」と1問だけ聞く |
| [ヒーロー](hero.md) | Instagramのプロフィールから、体験レッスン・教室の紹介・生徒さんの声へ案内する |
| [オンボーディング](onboarding.md) | 「あなたに合うコース診断」。年齢、経験、弾きたい曲を聞いて、合うコースを案内する |
| [予約ブッキングファネル](appointment-booking.md) | 体験レッスンの予約。空いている枠から選んでもらう |
| [ウェビナー](webinar.md) | 保護者向けの説明会。「家での練習に、どう声をかけるか」を話し、入会を案内する |
| [トリップワイヤーファネル](tripwire-funnel.md) | 練習用の伴奏音源や、指づかいを書き込んだ楽譜を低価格で届ける |
| [ブックファネル](book-funnel.md) | 「大人の初心者向けの練習法」をまとめた小冊子を送料のみで届け、動画レッスンを追加で案内する |
| [デジタルダウンロードファネル](digital-download-funnel.md) | オリジナルの教材、練習カード、楽典ドリルの販売 |
| [オンラインコースファネル](online-course-funnel.md) | 動画で進められる「両手で弾けるまでの8週間」講座 |
| [メンバーシップファネル](membership-funnel.md) | 月額のオンライン教室。毎月の課題曲、添削、質問会 |
| [チャレンジファネル](challenge-funnel.md) | 「5日間で1曲のサビを弾く」無料チャレンジ。最終日に講座を案内する |
| [VSL(ビデオセールスレター)ファネル](vsl-funnel.md) | 講座の中身と生徒さんの変化を1本の動画で伝え、そのまま申し込みへ |
| [商品ローンチファネル](product-launch-funnel.md) | 新しい講座を始める前に、無料の動画を数日かけて届けてから募集する |
| [申込式ハイチケットファネル](application-funnel.md) | 音大受験やコンクールに向けた個別指導。申込フォームと面談で、合うかどうかを確かめる |
| [サミットファネル](summit-funnel.md) | 複数の先生が1テーマで話すオンラインの集まり。たとえば「大人から始める楽器」 |

### 演奏家・作曲家の場合

| 型 | 使い方の例 |
| --- | --- |
| [リードジェネレーション](lead-generation.md) | 未発表の音源や、楽曲の制作ノートを、登録と引き換えに渡す |
| [オプトイン](opt-in.md) | 公演と新作の案内を受け取る読者登録 |
| [アスクキャンペーンファネル](ask-campaign-funnel.md) | 講座を作る前に「作曲を始めるとき、いちばん困っていることは？」と1問だけ聞く |
| [ヒーロー](hero.md) | SNSのプロフィールから、新譜、公演のチケット、グッズ、読者登録へ案内する |
| [オンボーディング](onboarding.md) | 「あなたへのおすすめの1曲」診断。気分や好みを聞いて、作品の入口を案内する |
| [予約ブッキングファネル](appointment-booking.md) | 演奏や作編曲の依頼の、事前相談の予約 |
| [ウェビナー](webinar.md) | 新作の解説会や、制作の裏側を話すオンラインの会。最後に作品や会員の案内をする |
| [トリップワイヤーファネル](tripwire-funnel.md) | 楽譜1曲、ライブ音源、小冊子を低価格で届け、追加で映像やセットを案内する |
| [ブックファネル](book-funnel.md) | 教則本や楽譜集を入口に、解説動画つきの講座を追加で案内する |
| [デジタルダウンロードファネル](digital-download-funnel.md) | 楽譜、音源、ライナーノーツのPDFの販売 |
| [オンラインコースファネル](online-course-funnel.md) | 自分の専門(作曲、編曲、奏法)を教える講座 |
| [メンバーシップファネル](membership-funnel.md) | ファンクラブ。先行公開、制作日記、会員だけの配信 |
| [チャレンジファネル](challenge-funnel.md) | 「5日間で8小節を作曲する」無料チャレンジ。最終日に講座を案内する |
| [VSL(ビデオセールスレター)ファネル](vsl-funnel.md) | 作品や企画の背景を動画で語り、そのまま予約や購入へ |
| [商品ローンチファネル](product-launch-funnel.md) | アルバムの発売前に、曲ごとの物語を動画で数日かけて届けてから予約を受け付ける |
| [申込式ハイチケットファネル](application-funnel.md) | 記念の楽曲制作や、行事での演奏の依頼。申込フォームと面談で内容を詰める |
| [サミットファネル](summit-funnel.md) | 同じジャンルの演奏家が集まるオンラインの催し |

### 型を組み合わせる

1本で完結させる必要はありません。入口の型と、その先の型をつなぐと、流れができます。

- **教室の例:** 練習メニューのPDF(リードジェネレーション) → 体験レッスンの予約(予約ブッキング) → 入会
- **講座の例:** 無料チャレンジ(チャレンジ) → 講座の申し込み(オンラインコース) → 月額の教室(メンバーシップ)
- **演奏家の例:** プロフィールの入口(ヒーロー) → 読者登録(オプトイン) → 新譜の予約(商品ローンチ)

つなぎ目になるのは、登録後や購入後に届くメールです。型ごとのメールの並びは、[型別・登録後と購入後の自動メール](follow-up-emails.md)にまとめています。
