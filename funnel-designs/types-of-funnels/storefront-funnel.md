# ストアフロントファネル

{% hint style="info" %}
ストアフロントファネルは、マーケター Russell Brunson(ラッセル・ブランソン)が紹介しているファネルの型のひとつです。お店の「店先」のように商品を数点だけ並べ、選んだ商品ごとに、その商品に合わせた注文の流れへ案内します。
{% endhint %}

### ストアフロントファネルとは？

ストアフロントファネルは、少数の商品を1ページに並べ、気になった商品を押すと、その商品の注文ページへ進むファネルです。

ファネルは本来、1つの商品に絞って案内する型です。けれども、扱うものが数点あり、どれが合うかは相手によって違う、という場面があります。そのときに入口として使うのがこの型です。並べるところまではお店のように見せ、選んだあとは1商品に絞った流れへ進めます。

### オンラインショップとの使い分け

OpusBoosterには[オンラインショップ](../../platform/online-shop/shop-overview.md)の機能もあります。どちらを使うかは、商品の数と目的で決めます。

| | ストアフロントファネル | オンラインショップ |
| --- | --- | --- |
| 商品の数 | 数点(目安は3〜6点) | 多数 |
| 見せ方 | 1ページに並べる | カテゴリーで分けて探してもらう |
| 選んだあと | その商品の注文ページへ進む | カートに入れて、まとめて会計する |
| 向いている場面 | 新商品を試す、期間限定の企画、既存のお客様への案内 | 常設の売り場 |

数点から始めて、商品が増えてきたらオンラインショップへ移る、という進め方もできます。

### こんな場面で使えます

- **教室の先生** – 体験レッスン、月謝のコース、教材を1ページに並べて、それぞれの申込ページへ案内する。
- **演奏家・作曲家** – 新譜、楽譜、グッズを数点だけ並べて、公演の時期に合わせて案内する。
- **講師・コーチ** – 入門・実践・個別の3つの講座を並べて、段階に合うものを選んでもらう。
- **すでにお客様がいる場合** – 「次はこちら」と案内する、既存のお客様向けの売り場として使う。

### ファネル概要

このファネルは、次の3ステップで構成されます。

1. ストアフロントページ(商品を並べるページ)
2. 注文ページ
3. サンキューページ

### 先に商品を登録する

並べる商品は、先にストアへ登録しておきます。登録のしかたは[商品の作成](../../platform/online-shop/create-products.md)をご覧ください。画像は、すべて同じ縦横の比率でそろえると、並べたときに整って見えます。

### ストアフロントページ

商品の並べ方は2つあります。

**方法1: ストアウィジェットで並べる**

[ストアウィジェット](../../platform/widgets/store-widget.md)をページに置き、「商品の編集」で「選択した商品」を選んで、並べたい商品を指定します。

ストアのプロセスは「今すぐ購入」にします。押すとそのまま決済の画面へ進むので、1商品に絞った流れになります。「カートに追加」は、複数の商品をまとめて買ってもらうオンラインショップ向けの設定です。

商品に割引を設定している場合は、割引バッジで「セール品」や割引率を商品の上に表示できます。

**方法2: 画像とボタンで作り、商品ごとの注文ページへ送る**

商品ごとに、画像、短い説明、ボタンを並べ、ボタンの行き先を、その商品の注文ページ(ファネルステップ)にします。

手間はかかりますが、商品ごとに説明の文章やバンプオファー、購入直後の追加提案を変えられます。商品によって買う人の関心が大きく違うときは、こちらが向いています。

| | 方法1: ストアウィジェット | 方法2: 画像とボタン |
| --- | --- | --- |
| 作る手間 | 少ない | 商品の数だけページを作る |
| 商品ごとの説明 | 商品に登録した内容が出る | 自由に書ける |
| 商品ごとのバンプオファーや追加提案 | — | 商品ごとに決められる |

### 並べ方のこつ

- **数を絞る。** 選択肢が多いほど、決められずに閉じる人が増えます。
- **いちばん勧めたいものを先頭に置く。** 迷った人は、最初に目に入ったものを選びます。
- **商品名だけでなく、誰に向くかを一言添える。** 「はじめての方に」「もう一歩進みたい方に」のように書くと、自分で選べます。
- **ページの上に、選び方を一文で書く。** 「迷ったら、まず体験レッスンから」と書いてあるだけで、動きやすくなります。

### 注文ページ

方法2で作る場合は、商品ごとに注文ページを用意し、[チェックアウトウィジェット](../../platform/widgets/checkout-widget.md)を置きます。ここでバンプオファーを足したり、[アップセル](../../platform/funnels/upsell-downsell.md)を続けたりできます。

紙の商品やグッズを送る場合は、配送先住所の入力を有効にします。

### サンキューページ

購入へのお礼と、受け取り方を伝えます。あわせて、ストアフロントページへ戻るボタンを置いておくと、ほかの商品も見てもらえます。

### 1商品だけを期間限定で売る場合

並べる商品を1つに絞り、期間を区切って売る使い方もあります。発売記念や、公演に合わせた数日だけの企画に向いています。

この場合は、ストアフロントページを省いて、注文ページとサンキューページの2ステップにします。注文ページの上部に[カウントダウンウィジェット](../../platform/widgets/countdown-widget.md)を置き、締め切りの日時を見せます。

{% hint style="warning" %}
締め切りを書いたら、その日時で必ず終えてください。過ぎても買える状態が続くと、次に期限を書いたときに信じてもらえなくなります。
{% endhint %}

### 購入後の自動メール

購入した方へのメールと、注文の途中で離れた方へのフォローは、ほかの販売の型と同じです。並びは[型別・登録後と購入後の自動メール](follow-up-emails.md)の「買ってもらう型」をご覧ください。

### 案内する前の確認

- 並べた商品の画像、名前、価格が、いまの内容になっているか
- 各商品のボタンが、正しい注文ページへ進むか
- 低価格の商品で実際に一度買ってみて、サンキューページまで進めたか
- 購入直後のメールが届くか
- 期限を書いた場合、その日時で終える手はずになっているか

共通の確認点は、[ファネルを案内する前のチェックリスト](pre-launch-checklist.md)をご覧ください。
