# 型別・登録後と購入後の自動メール

ファネルは、ページを作っただけでは半分です。登録や購入のあとに届くメールがあって、はじめて次の一歩につながります。

この記事では、ファネルの型を目的ごとに4つに分け、それぞれで用意しておくメールの並びを紹介します。全部を一度に作る必要はありません。まずは各表の1通目だけを用意して、あとから足していけば十分です。

### 最初に: メールが動き出す仕組み

自動メールは、[オートメーション](../../platform/email-and-automation/automation.md)で作ります。動き出すきっかけは、主に次の2つです。

| きっかけ | 設定する場所 |
| --- | --- |
| フォームやクイズからの登録 | フォーム設定で、リストにつなぎ、タグを付ける |
| 商品の購入 | チェックアウトの設定で、購読者リストに追加し、タグを付ける |

{% hint style="warning" %}
フォームやチェックアウトをリストにつないでいないと、登録や注文は入っても、自動メールは1通も届きません。「登録はあるのにメールが出ていない」ときは、最初にここを確かめてください。
{% endhint %}

注文確認、予約の確認、パスワードの再設定などは、[システムメール](../../platform/system-emails/README.md)として最初から用意されています。この記事で扱うのは、その先の「関係を育てるメール」です。

### 1. 登録してもらう型

対象: [リードジェネレーション](lead-generation.md)、[オプトイン](opt-in.md)、[ヒーロー](hero.md)、[オンボーディング](onboarding.md)、[アスクキャンペーンファネル](ask-campaign-funnel.md)、[ブリッジファネル](bridge-funnel.md)

| 送る時期 | 内容 |
| --- | --- |
| 登録直後 | お礼と、約束した特典の受け取り方 |
| 翌日 | 特典の使い方。最初にどこを見ればよいか |
| 数日おきに数通 | 特典のテーマに沿った補足、実例、よくある質問への答え |
| 1〜2週間後 | 次の一歩(体験レッスン、個別相談、入口の商品)の案内 |

1通目は、登録から数分以内に届くようにします。届くのが遅いと、特典を頼んだこと自体を忘れられてしまいます。

クイズを使うオンボーディングでは、答えごとにタグを付けておくと、2通目以降の内容を相手に合わせて分けられます。

アスクキャンペーンでは、受付を締め切ったあとに「いただいた声をもとに、こう決めました」という報告を1通入れます。

### 2. 決まった日時に来てもらう型

対象: [ウェビナー](webinar.md)、[サミットファネル](summit-funnel.md)、[チャレンジファネル](challenge-funnel.md)、[商品ローンチファネル](product-launch-funnel.md)

| 送る時期 | 内容 |
| --- | --- |
| 登録直後 | 参加の確認、日時、参加方法。カレンダーへの登録のお願い |
| 前日 | リマインド。当日に何が分かるかを一文で |
| 当日(開始の少し前) | 参加用のリンクだけを載せた短いメール |
| 各回の公開時 | 複数日の企画では、その日の動画やページへのリンクを毎回送る |
| 終了直後 | リプレイの案内と、紹介した商品の案内 |
| 受付の締め切り前 | 締め切りの日時と、残りの時間 |

この型では、登録した人のうち実際に参加するのは一部です。来てもらえるかどうかは、リマインドのメールでほぼ決まります。

サミットやチャレンジのように数日続く企画では、「その日の分を見られるのはその日だけ」と区切ると、当日のうちに見てもらいやすくなります。あとからまとめて見たい人には、全編を見られる有料のパスを案内します。

### 3. 買ってもらう型

対象: [トリップワイヤーファネル](tripwire-funnel.md)、[ブックファネル](book-funnel.md)、[ストアフロントファネル](storefront-funnel.md)、[VSL(ビデオセールスレター)ファネル](vsl-funnel.md)、[デジタルダウンロードファネル](digital-download-funnel.md)、[オンラインコースファネル](online-course-funnel.md)、[メンバーシップファネル](membership-funnel.md)

| 送る時期 | 内容 |
| --- | --- |
| 購入直後 | お礼と、商品の受け取り方(ダウンロード、ログイン、発送時期) |
| 数日後 | 使い始めの案内。最初にやってほしいことを1つだけ |
| 1週間後 | つまずきやすい点への答え。感想を聞く |
| 追加の提案を断った方へ | 購入直後に断った商品を、理由を添えてもう一度案内 |
| 2〜3週間後 | 次の段階の商品や、個別相談の案内 |

あわせて、注文フォームの途中で離れた方には、[カゴ落ちの自動化](../../platform/email-and-automation/abandoned-cart-automation.md)で続きを案内できます。チェックアウトを2ステップにしておくと、1ステップ目で入力されたメールアドレスに送れます。

メンバーシップでは、入会直後の数日が続くかどうかの分かれ目です。「まずこの1本を見てください」と、最初の一歩を具体的に示すメールを入れておきます。

### 4. 話す約束をもらう型

対象: [予約ブッキングファネル](appointment-booking.md)、[申込式ハイチケットファネル](application-funnel.md)

| 送る時期 | 内容 |
| --- | --- |
| 予約・申込の直後 | 受付の確認、日時、当日の進め方 |
| 予約の直後〜前日 | 事前に見ておいてほしい動画や資料 |
| 前日 | リマインド。準備しておいてほしいこと |
| 当日 | 接続先や場所の案内 |
| 終了後 | お礼と、話した内容のまとめ、次の手続き |
| 申込だけで予約が無い方へ | 予約ページへの案内をもう一度 |

予約の確認とリマインドは、システムメールにも用意があります。設定は[スケジュール予約](../../platform/appointments/schedule-booking.md)をご覧ください。

個別相談は、当日に来てもらえないことがいちばんの損失です。事前に動画や資料を見てもらうと、来てもらえる割合が上がり、当日の話も早く進みます。

### 書くときの共通の決まり

- **1通に、してほしいことは1つだけ。** リンクを並べると、どれも押されません。
- **件名で中身が分かるようにする。** 「ご登録ありがとうございます」より「特典の受け取り方」のほうが開かれます。
- **本文のリンクは、押せるリンクにする。** URLを文字のまま貼ると、クリック数に数えられません。
- **売り込みは後半に置く。** 先に役に立つ内容を送り、案内はそのあとにします。

### 届かないときの確認点

1. フォーム、またはチェックアウトが、リストにつながっているか
2. オートメーションがオンになっているか
3. [メール送信用のドメイン](../../platform/email-and-automation/email-domain-connection.md)の接続が済んでいるか
4. 自分のアドレスでテスト登録をして、1通目が届くか
