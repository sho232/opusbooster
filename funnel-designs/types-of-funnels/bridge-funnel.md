# ブリッジファネル

{% hint style="info" %}
ブリッジファネルは、マーケター Russell Brunson(ラッセル・ブランソン)が紹介制度(アフィリエイト)での紹介の型として広めたものです。紹介制度に限らず、チケット販売サイトや配信サービスのように、自分では中身を変えられないページへ人を送る場面で使えます。
{% endhint %}

### ブリッジファネルとは？

ブリッジファネルは、他社のサイトにある申込ページへ人を送る前に、自分のページを2枚挟むファネルです。1枚目で連絡先を受け取り、2枚目で「なぜこれを勧めるのか」を自分の言葉で伝えてから、相手のページへ送ります。

SNSやメールから、他社の申込ページへ直接リンクを貼ると、次の3つが起こります。

- **連絡先が残りません。** 誰が興味を持ってくれたのかが分からず、次の案内ができません。
- **勧める理由が伝わりません。** 相手のページは、あなたの読者に向けて書かれたものではないからです。
- **その場で申し込まなかった人に、もう一度声をかけられません。**

間に自分のページを挟むと、申し込みに至らなかった人も含めて、興味を持った人とのつながりが手元に残ります。「橋(ブリッジ)」という名前は、いま読者がいる場所と、送りたい先との間をつなぐ、という意味です。

### こんな場面で使えます

- **演奏家** – チケット販売サイトや配信サービスへ送る前に、公演や作品の背景を伝える。
- **教室の先生** – 自分が使っている教材や、信頼している楽器店の販売ページを紹介する。
- **講師・コーチ** – 知人の講座や、共同で開く企画の申込ページ(相手側のサイト)を紹介する。
- **まだ自分の商品が無い人** – 将来扱いたい分野で、考え方の合う他社の商品を紹介しながら、その分野に関心のある読者を先に集める。

### ファネル概要

このファネルは、次の2ステップで構成されます。

1. 登録ページ
2. ブリッジページ(ここから他社の申込ページへ)

OpusBoosterでは、同じ2ステップの[リードジェネレーション](lead-generation.md)のテンプレートを土台にします。サンキューページを、ブリッジページに作り替えます。

### 登録ページ

登録ページは、できるだけ簡素にします。置くのは、見出し、短い説明、フォームの3つです。

見出しでは、読者がいちばん欲しい結果を約束します。紹介する商品の名前ではなく、その先で手に入るものを書きます。

| 書き方 | 例 |
| --- | --- |
| 商品の名前を出す | 〇〇社の練習アプリのご紹介 |
| 欲しい結果を約束する | 毎日10分で、譜読みが止まらなくなる練習のしかた |

登録と引き換えに渡すものを用意しておくと、登録してもらいやすくなります。自分が実際に使ってみた感想をまとめたメモや、使い方の手引きが向いています。

{% hint style="info" %}
このページに、長い説明や紹介の動画を入れないでください。ここでの目的は連絡先を受け取ることです。説明は、次のブリッジページで行います。
{% endhint %}

フォームの設定では、送信後の行き先をブリッジページのステップにし、リストにつなぎます。設定のしかたは[フォームウィジェット](../../platform/widgets/form-widget.md)をご覧ください。

### ブリッジページ

登録の直後に表示するページです。上から順に、次の4つを置きます。

1. **短い動画** – 自分は誰か、なぜこれを勧めるのかを話します。
2. **手に入るもの** – 相手の商品の中身を、箇条書きで並べます。
3. **自分からの特典** – ここから申し込んだ方にだけ渡すものがあれば、その中身。
4. **手順とボタン** – 「下のボタンから申し込む → 申込完了のメールを転送する → 特典を受け取る」のように、次にすることを順番に書きます。

動画は、上手に話す必要はありません。売り込みの動画ではなく、使った人としての正直な感想を話します。良い点だけでなく、気になった点も一つ添えると、実際に使った人の言葉として伝わります。

動画を用意できない場合でも、「次のページで何を見ることになるか」だけは文章で伝えてください。行き先が見えないまま他社のサイトへ移ると、多くの人はそこで閉じてしまいます。

ボタンには、相手の申込ページのアドレスを入れます。

### 特典を渡す場合

相手のサイトでの申し込みは、こちらからは見えません。特典を用意するときは、渡し方を決めておきます。

- 申込完了のメールを、こちらへ転送してもらう
- 専用のフォームを用意して、申込時の名前とメールアドレスを入れてもらう

特典は、申し込みが済んでから渡します。先に渡してしまうと、申し込む理由がなくなります。

### 紹介するときの注意

{% hint style="warning" %}
紹介によって報酬を受け取る場合は、そのことをページに明記してください。また、紹介制度には、広告での利用や表現について、提供元ごとの決まりがあります。始める前に、相手先の規約を確かめてください。
{% endhint %}

### すでに読者がいる場合

すでにメールやLINEの読者がいる場合も、紹介を全員へ何度も送るのではなく、同じ流れを使います。

まず「こういうものに興味はありますか」と一度だけ知らせ、登録した人にだけ、続きのメールを送ります。興味のない人へ同じ案内を重ねずに済み、読者との関係を保てます。すでに読者である人にあらためて登録してもらうのは、本人に「知りたい」と選んでもらうためです。

### 登録後の自動メール

ブリッジページで申し込まなかった方にも、[オートメーション](../../platform/email-and-automation/automation.md)で続きを届けます。

| 送る時期 | 内容 |
| --- | --- |
| 登録直後 | お礼、約束した特典、ブリッジページへのリンク |
| 翌日 | 自分が使ってみて変わったこと |
| 数日後 | よく聞かれる質問への答え |
| 締め切りがある場合はその前 | 締め切りの日時と、特典の内容をもう一度 |

ほかの型のメールの並びは、[型別・登録後と購入後の自動メール](follow-up-emails.md)にまとめています。

### 案内する前の確認

- 登録すると、ブリッジページへ進むか
- ブリッジページのボタンが、相手の正しい申込ページを開くか
- フォームがリストにつながっていて、1通目のメールが届くか
- 特典の受け取り方が、ページとメールの両方に書いてあるか
- 報酬を受け取る紹介の場合、その旨を明記したか

共通の確認点は、[ファネルを案内する前のチェックリスト](pre-launch-checklist.md)をご覧ください。
