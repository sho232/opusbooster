# ファネルを案内する前のチェックリスト

ファネルができあがったら、SNSやメールで案内する前に、ひととおり自分で通してみてください。どの型のファネルにも共通する確認点を、上から順に並べています。

いちばん確実なのは、**お客様と同じ道をたどること**です。自分のメールアドレスで登録し、買うものがあれば買い、届いたメールを開くところまで進めます。

### 1. ページ

- 誤字や、テンプレートのサンプル文が残っていないか
- 画像と動画が表示され、動画は再生できるか
- ボタンとリンクが、すべて正しい行き先に進むか
- スマートフォンの幅で見たとき、文字や画像が崩れていないか([モバイル編集](../../platform/website-funnel-builder/mobile-editing.md))
- 日付、金額、定員が、いまの内容になっているか

{% hint style="info" %}
以前のファネルを複製して作ったときは、日付と金額を特に念入りに見てください。前回の数字が1か所だけ残っている、という見落としがいちばん多い場所です。
{% endhint %}

### 2. フォームと登録

- フォームを送信すると、次のステップ(サンキューページなど)へ進むか
- フォームが、リストにつながっているか
- 登録した人に、決めたタグが付くか
- 連絡先に、登録した内容が正しく入っているか

{% hint style="warning" %}
フォームをリストにつなぎ忘れると、登録は入るのに、自動メールもメルマガも届きません。画面上は何も問題なく見えるので、テスト登録で1通目が届くところまで必ず確かめてください。
{% endhint %}

### 3. 決済(商品を売る場合)

- [決済サービス](../../platform/online-shop/payment-services.md)の接続が済んでいるか
- チェックアウトに、正しい商品と金額が入っているか
- バンプオファーにチェックを入れたとき、合計金額が正しく変わるか
- アップセルを「買う」「断る」の両方で、次のページへ進むか
- 購入後のサンキューページに、受け取り方が書いてあるか
- 特定商取引法に基づく表記を用意したか([個人の場合](../../platform/online-shop/tokushoho-setup-individual.md)／[法人の場合](../../platform/online-shop/tokushoho-setup-corporate.md))
- 発送や提供の時期をページに書いた場合、そのとおりに守れるか

確かめるときは、低価格の商品で実際に一度買ってみるのが確実です。

### 4. メール

- [メール送信用のドメイン](../../platform/email-and-automation/email-domain-connection.md)の接続が済んでいるか
- オートメーションがオンになっているか
- 登録直後・購入直後の1通目が、数分以内に届くか
- メール内のリンクが、正しいページへ進むか
- 差出人の名前と、返信先のアドレスが正しいか

型ごとに用意しておくメールの並びは、[型別・登録後と購入後の自動メール](follow-up-emails.md)にまとめています。

### 5. アドレスと見え方

- [独自ドメイン](../../platform/getting-started/custom-domain.md)を使う場合、そのアドレスでページが開くか
- SNSにリンクを貼ったとき、意図した画像と説明文が出るか([ファビコンとSNSシェア](../../platform/website-funnel-builder/favicon-social-share.md))
- ページのアドレスが、人に伝えやすい短さになっているか

### 6. 計測

- ファネルの目標が、登録や購入のステップに設定されているか
- テスト登録やテスト購入が、ファネルの分析に数えられているか

案内を始める前に数字が取れる状態にしておくと、あとで「どこで離れているか」を確かめられます。見出しやボタンを比べたいときは、[A/Bスプリットテスト](../../platform/funnels/ab-split-testing.md)が使えます。

### 7. 案内を始めたあと

- 最初の数件は、登録や注文が入るたびに、連絡先とメールの送信状況を自分の目で確かめる
- テストで入れた自分の登録や注文は、集計から外すか、数に入っていることを覚えておく
- 問い合わせが来たら、同じ質問が出ないように、ページかメールに一文足す
