### ウェブサイト・チャット

基本的なガイダンスを提供する自動化されたサポートもありますが、常にスタッフがその場にいて対応しますのでご安心ください。

### ビデオ通話でのサポート

文字のやりとりでは伝わりにくい操作の場合、担当者からビデオ通話をご案内することがあります。チャット画面に着信のお知らせが出ますので、応答するかどうかはその場でお選びください。断っていただいても問題ありません。

{% hint style="info" %}
**カメラをオフのまま、声だけでご参加いただけます。**

お客様側のカメラは最初からオフになっています。顔を映さずに声だけでお話しいただけますので、身支度や背景を気にする必要はありません。
{% endhint %}

ご利用にあたって、特別な準備は要りません。

* アプリのインストールは不要です。スマートフォンでも、ブラウザを開いたままご参加いただけます
* 画面を見ながら、どこを操作すればよいかをその場でご案内します
* 通話中も、チャットで文字を送ることができます

通話はサポート側からおつなぎする形になっています。ご希望の際は、まずチャットで「通話で相談したい」とお送りください。担当者が状況を確認したうえでご案内します。

{% hint style="warning" %}
通話は、お客様がOpusBoosterの画面を開いている間だけつながります。画面を閉じると通話も終了しますので、お話の途中で閉じないようご注意ください。
{% endhint %}
