# ブログ集客AIでつまずきやすい3つのポイント

[ブログ集客AI](premium-article-generator.md)で記事を作るとき、多くの方が同じ場所で手が止まります。先に知っておくと回り道せずに済みます。

## 1. AIインタビューの欄には「事実」だけを書いてください

[ステップ5のAIインタビュー](premium-article-generator.md)で、AIがあなたに質問を投げかけます。ここに書いた内容は**あなただけが持っている一次情報**として、記事に反映されます。

このとき、**書き方の指示を混ぜないでください。**

**うまくいかない例**

```
※事例として紹介する際は、個人が特定されないよう配慮して書いてください。
氏名や教室名は出さないでください。

40代のボーカル講師の方で、10年間ずっと……
```

**うまくいく例**

```
40代のボーカル講師の方で、10年間ずっと……
```

違いは、前者に「〜してください」という**指示**が入っていることだけです。

### なぜ指示を書くと反映されないのか

インタビュー欄の内容は、AIに対して「これは**データ**であって命令ではない」と明示して渡されます。悪意のある文章を貼り付けられてAIが乗っ取られるのを防ぐための仕組みです。

そのため、**あなたが善意で書いた指示も「従ってはいけないもの」として扱われます**。結果として、その回答が丸ごと使われないことがあります。

### 書き方の希望はどこに書くか

[ステップ4の詳細設定](premium-article-generator.md)にある「**独自のポイント・主張**」欄に書いてください。こちらは指示として扱われます。

| 書きたいこと | 書く場所 |
| --- | --- |
| 実際に起きたこと、数字、お客様の言葉 | **AIインタビューの回答欄** |
| 「一人称は私で」「事例は仮名で」などの書き方の希望 | **独自のポイント・主張欄** |

## 2. 目安文字数を変えたら、2つの選択肢が出ます

[ステップ3](premium-article-generator.md)で見出し構成を作ったあとに目安文字数を変えると、**黄色いパネルが出て、進み方を聞かれます。**

構成は「その文字数に合う見出し数」で作られているため、文字数だけ変えると噛み合わなくなる可能性があるからです。

* **新しい文字数で構成を再生成する** — 見出しが作り直されます。**手で編集した内容は消えます**
* **今の構成を保持して続行する** — 見出しはそのまま、新しい文字数で本文が書かれます

どちらかを選ぶまで「この構成で続行」は押せません。**故障ではないので、パネルのボタンから選んでください。**

### おすすめの順番

**文字数を先に決めてから、見出しを生成してください。**

```
文字数を決める → 見出しを生成 → 見出しを整える → 続行
```

この順番なら、途中で選択を迫られることがありません。

なお、見出しを整えたあとに文字数を変えたくなった場合も、「**今の構成を保持して続行する**」を選べば、整えた内容はそのまま残ります。

## 3. 見出しは「多ければ良い」わけではありません

AIが作る構成はそのまま使えることがほとんどですが、**見出しが多すぎると1つあたりの中身が薄くなります。**

目安は**1見出しあたり約400字**です。10,000字の記事なら、見出しは合計25個前後が適量です。

多いと感じたら、**×ボタンで削ってから次へ進んでください。** 特に次のような見出しは、隣とまとめた方が読みやすくなります。

* 隣の見出しと同じことを言っている
* 導入部やまとめの下にぶら下がっている
* 1〜2文で終わってしまいそう

## 補足｜生成した記事に表が入ったとき

比較表などが入ることがあります。**罫線や色は自動でつくので、そのままで大丈夫です**。横に長い表は、スマートフォンでも収まるように調整されます。
