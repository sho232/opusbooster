# ブログ設定

ブログ全体の設定を変更するには、ブログ投稿の一覧画面で右上の［設定］をクリックします。設定画面が開きます。

![](../../.gitbook/assets/BlogSetting.png)

この画面では、次のことができます。

| 項目 | 内容 |
| :--- | :--- |
| ブログ一覧ページにサイドバーを追加 | 記事一覧の横にサイドバーを表示します |
| 記事に推定読了時間を表示 | 「読了まで約◯分」を記事に表示します |
| 記事に読了プログレスバーを表示 | 読み進めた割合を示すバーを画面に表示します |
| シェアボタンを追加 | Facebook・X（Twitter）・LinkedInから、使うものを個別に選べます |
| コメントを有効にする | 読者がコメントを投稿できるようになります |
| 新規コメントの通知を送信する | コメントが届いたときにお知らせを受け取ります |
| 記事タイトルの標準フォント | 記事タイトルに使うフォントを選びます |

設定を変えたら、［保存］を押してください。

{% hint style="info" %}
**推定読了時間と読了プログレスバーについて**\
どちらも「この記事はどれくらいで読み終わるか」を読者に伝える機能です。長めの記事を書く方は、離脱を防ぐ効果が期待できます。まずはどちらか一方から試してみてください。
{% endhint %}
