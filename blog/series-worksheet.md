# シリーズ記事3本の設計シート

記事を書き始める前に、この1枚を埋めてください。**3本の役割分担を先に決めておくと、途中で迷いません。**

書くのは1本あたり2〜3行です。完璧に埋める必要はありません。

## なぜ3本を先に設計するのか

1本ずつ思いついた順に書くと、読者は1本目を読んで、そこで終わります。

3本に役割を持たせて、**それぞれの終わりで次を予告しておく**と、読者は最後まで読み進みます。3本目まで読んだ読者は、あなたのことをかなり深く知っている状態になります。

この「次が気になる状態で終える」やり方をオープンループと呼びます。詳しくは[シリーズ機能と次回予告（Open Loop）の使い方](series-and-open-loop.md)をご覧ください。

## 3本の役割

| | 役割 | 読者の状態 |
|---|---|---|
| **1本目** | 入口。悩みを言葉にする | 「これ、自分のことだ」と気づく |
| **2本目** | 深掘り。やり方を示す | 「やってみようかな」と思う |
| **3本目** | 行動。事例と次の一歩 | 「この人に相談してみようかな」と思う |

**1本目でいきなり売らないでください**。3本かけて温度を上げるのがシリーズの目的です。

## 記入例

ボーカル講師の方の例です。

### 1本目

| 項目 | 記入内容 |
|---|---|
| テーマ | 高い声が出ないのは、喉の使い方ではなく息の量の問題 |
| 狙うキーワード | 高い声 出ない 原因 |
| 読み終えた読者がどうなるか | 「喉を鍛える練習をしていたのが逆効果だったかも」と気づく |
| 最後に予告すること | 次回、自宅でできる息の量の測り方を紹介します |

### 2本目

| 項目 | 記入内容 |
|---|---|
| テーマ | 自宅でできる、息の量を整える3分の練習 |
| 狙うキーワード | 高い声 出す 練習 自宅 |
| 読み終えた読者がどうなるか | 今日から試せる練習が1つ手に入る |
| 最後に予告すること | 次回、3ヶ月続けた方がどう変わったかをお話しします |

### 3本目

| 項目 | 記入内容 |
|---|---|
| テーマ | 3ヶ月で変わった方の話と、変わらなかった方の違い |
| 狙うキーワード | ボイトレ 効果 期間 |
| 読み終えた読者がどうなるか | 「独学の限界」を自分の言葉で理解する |
| 次に取ってほしい行動 | 無料の体験レッスンに申し込む |

※この事例は、実際の支援経験をもとに再構成したものです。

## このシートを、シリーズ機能にどうつなぐか

**このシートの欄は、そのまま入力欄に対応しています**。別々に考える必要はありません。

| シートの欄 | 入力する場所 |
|---|---|
| シリーズ名 | ステップ4「シリーズ設定」の〔**シリーズ名**〕（3本とも同じ名前） |
| テーマ | ステップ1の〔**テーマ**〕 |
| 狙うキーワード | ステップ1のキーワード欄 |
| 最後に予告すること | ステップ4「シリーズ設定」の〔**次回テーマ**〕 |

2本目を作るときは、ステップ1の「**📖 シリーズの続きを書く**」から自分のシリーズ名を選んでください。**前の記事で書いた〔次回テーマ〕が、そのままテーマ欄に入ります**。つまり、シートに書いた予告がそのまま次の記事の出発点になります。

{% hint style="warning" %}
**〔次回テーマ〕を空欄のままにしないでください。**

空欄で生成すると、AIが本文の流れを読んで予告テーマを自動で決めます。その内容は、あなたがシートに書いた2本目・3本目の計画とは違うものになることがあります。そして次に「シリーズの続きを書く」を選んだとき、**AIが決めた方のテーマが入ってきます。**

シートを埋めた方は、必ず〔次回テーマ〕にシートの内容を入れてください。
{% endhint %}

もし違うテーマが入ってきても、**テーマ欄はそのまま書き換えられます**。すでにテーマを入力していた場合は「置き換えますか？」と確認が出るので、勝手に消えることはありません。

**書いているうちに、AIの提案の方が良いと思ったら、シートの方を書き換えてください**。このシートは計画を固定するためのものではなく、迷ったときに戻る場所です。

## 埋め終わったら

**キーワードの欄が埋まらないときは、先に[ドリーム100キーワード](dream-100-keywords.md)を使ってください**。100個の候補から選ぶ方が、ゼロから考えるより早いです。

3本分そろったら、1本目から順に[ブログ集客AI](premium-article-generator.md)で作っていきます。

## うまくいかないときの目安

* **3本とも似た内容になった** — 役割が分かれていません。1本目を「気づき」、2本目を「やり方」、3本目を「事例」に寄せてみてください
* **予告することが思いつかない** — その記事で全部言い切ってしまっている可能性があります。1つ取っておいて次に回してください
* **3本目で何を勧めるか決まらない** — 無料相談・体験・メール登録など、**いちばん手前の一歩**にしてください。いきなり本商品に誘導すると読者が止まります
