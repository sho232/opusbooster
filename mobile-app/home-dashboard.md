# 管理画面（ホーム）の見方

**管理画面** は、サイトの状況を最初に確認する画面です。メニューから **管理画面** を押して開きます。

画面上部には「おかえりなさい、〇〇さん」と表示された歓迎バナーがあります。その下で、売上や注文の概要を確認できます。

## 最初に見る3つの数字

歓迎バナーの下には、3つの数値カードが並びます。サイトの状況を短時間で見たいときに役立ちます。

| カード | 確認できること |
| :--- | :--- |
| **売上高** | 売上の金額 |
| **受注** | 注文の件数 |
| **連絡先** | 連絡先の数 |

## 過去7日間の売上高を見る

**売上高（過去7日間）** では、過去7日間の合計金額を確認できます。前の期間と比べた増減率もバッジで表示されます。

グラフは棒グラフと折れ線で表示され、横軸は曜日です。日ごとの売上の動きを見たいときに使います。

## 最近の注文を確認する

**最近の注文** には、新しい注文が行ごとに表示されます。各行で、注文者、注文番号、商品名、金額、状態を確認できます。

注文が多いときは、右上の **すべて表示** を押します。状態は、たとえば **未入金** や **確定** のバッジで表示されます。

## 数字を見るときの注意

アプリのデータは、反映まで最大2時間かかる場合があります。直前の購入や連絡先の追加がすぐに数字へ出ないときは、時間をおいて確認してください。

確認するサイトを切り替えると、この画面のすべてのデータも切り替わります。上部中央のサイト名が、見たいサイトになっているか確認します。

## まとめ

- **管理画面** では、売上高、受注、連絡先をまとめて確認できます
- **売上高（過去7日間）** で、日ごとの売上の動きを確認できます
- **最近の注文** では、注文内容、金額、状態を確認できます
- データの反映には最大2時間かかる場合があります
