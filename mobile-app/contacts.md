# 連絡先を確認・追加する

OpusBoosterユーザー向け公式アプリでは、連絡先の一覧と詳細をスマホで確認できます。新しい連絡先の追加も、この画面から行えます。

## 連絡先画面を開く

左上の三本線を押してメニューを開き、**連絡先** を選びます。複数のサイトを運営している場合は、画面上部中央のサイト名を押して、確認したいサイトへ切り替えます。

画面を開いても連絡先が表示されず、「連絡先が見つかりません」と出ることがあります。そのときは画面を下に引っ張って離し、一覧を読み込みます。

## 一覧を探す・絞り込む

上部の **検索** に入力すると、連絡先を探せます。右側の赤い **+** は、新しい連絡先を追加する入口です。

画面には、次の3つの数字が表示されます。

| 表示 | 意味 |
| :--- | :--- |
| **表示中** | 今、一覧に表示している連絡先数です。 |
| **合計** | 連絡先の合計数です。 |
| **登録済み** | 登録済みの連絡先数です。 |

数字の下には、タグ・セグメントのチップが横に並びます。見たいチップを押すと、その条件に合う連絡先だけに絞り込めます。

一覧の各行には、アバター、表示名またはメールアドレス、**登録済み** の表示、メールアドレス、タグが並びます。行をタップすると、その連絡先の詳細を開けます。

## 連絡先の詳細とタグ

詳細画面では、大きなアバターとメールアドレスのほか、次の項目を確認できます。情報が入力されていない項目には **—** と表示されます。

| 項目 | 確認できる内容 |
| :--- | :--- |
| **名前** | 連絡先の名前です。 |
| **メール** | 連絡先のメールアドレスです。 |
| **電話** | 連絡先の電話番号です。 |
| **初回訪問** | 最初に訪問した情報です。 |

さらに情報を確認したいときは、**すべてのプロパティを表示** を押します。**タグ** の欄では、連絡先に付いているタグを確認できます。

タグを付けるときは、**+ タグの追加** を押します。付いているタグを外すときは、そのタグの **×** を押します。

## 新しい連絡先を追加する

右上の **+** を押すと、**新しい連絡先** のフォームが開きます。入力するのは **名前** と **メール** の2項目です。

必須なのは **メール** です。入力を終えたら **連絡先を追加** を押し、追加をやめる場合は **キャンセル** を押します。

## まとめ

* **検索** とタグ・セグメントで、必要な連絡先を探せます
* 一覧をタップすると、名前、メール、電話、初回訪問などの詳細を確認できます
* タグは **+ タグの追加** で付け、タグの **×** で外せます
* 新規追加では **名前** と **メール** を入力します
